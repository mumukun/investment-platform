# Change: CHG-20261116-003

## Title / Status

超跌反弹候选展示当日行情和操作依据 / RELEASED

## Description

接续 REL-20261116-001。候选列表增加现价、当日涨跌幅、来源时间和延迟状态。当天的候选请求批量读取现有行情。历史日期或缺失数据以「—」显示。验收覆盖真实隔离数据库、契约、桌面与手机预览，以及约 388 条候选的读取耗时。

补充同口径关键位的现价距离、风险比例、下一步条件、计划有效日、当日成交额与板块行业。价格基准无法核验或报价延迟时省略盘中距离。行业来自当前档案。候选评分、策略状态和排序由原策略生成。

## Release Impact and Rollback

选股服务与看板兼容增加可选 `display_quote`，发布时先选股服务。旧提供方缺字段时显示「—」。沿用现有事实表，无迁移。

## 主线整合（2026-11-16）

- 由当前主线整合到隔离分支，保留盘中筛选与收盘确认口径。无收盘确认的盘中参与信号也可在报价同口径时展示参与区间和失效距离。当天成交额仅用于展示，流动性核验仍取历史均额。
- 选股服务的规则与隔离 PostgreSQL 测试 15 项通过。使用新版 Provider 生成的合成数据验证看板，9 项接口契约测试、3 项页面 Vitest、定向 Ruff、类型检查和构建通过。
- 选股服务 6.18.0 [PR #106](https://github.com/mumukun/stock-analyzer/pull/106)，看板 2.18.0 [PR #87](https://github.com/mumukun/investment-research-dashboard/pull/87)。本轮交付限提交并合并，正式发布另行授权。
