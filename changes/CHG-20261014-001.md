## Scope

用户要求解决反复手动执行 NAS 发布命令的问题。当前免密 nas-image-release 只支持两个
CI_BUILD_ONCE 项目；marketNewsFeed 的旧 nas-deploy 虽然免密，但缺少正式全局锁与备份
控制，临时 flock 包装又不在免密范围。此次仅在 investment-platform 发布器增加已知
marketNewsFeed 的 SOURCE_TAG_BUILD 分支，复用 image-release-v1、同一全局锁与已有
nas-image-release deploy/preflight/verify sudoers，不增加泛化 sudo/shell 权限。

发布器安装本身不改业务源码、不升业务版本、不重启 v2.3.5；另两个项目的发布机制保持原路径。
源部署保留精确 Tag/main lineage、真实生产 SHA/Image ID、一次可读备份、旧镜像/私密
环境保留、原 deploy.sh、健康及认证只读 Admin API smoke。失败记录实际部分身份，
不自动数据库降级，不伪称采用 CI_BUILD_ONCE，也不建立应用 VERSION。

受保护备份，保留实际其他仓库命令，安装经过审查的代码并启用 source 配置。不修改
