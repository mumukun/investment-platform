# Change: CHG-20261115-002

## Title / Status
短线实验批次对账与平台突破四组排序对照 / RELEASED

## Description
接续 CHG-20261105-003 的持续强度研究。按原始交易日、批次标识与快照时刻关联模拟入账和收盘候选。新入账同一事务冻结实验名单。历史只读原始批次证据，找不到的逐日显示差额。

平台临界／突破启动按各收盘批次和交易板块，四组在同一批可评分候选中等量取前三分之一（向下取整）。四组为原排序、距突破位排序、持续强度排序及位置/强度百分位各半。结算沿用现有收盘模拟账本。以本地对账、实验结果和可按日与板块查看的演示验收。
