# Change: CHG-20261015-004

## Title / Status

简化投资研究登录页并替换拖动验证码 / RELEASED

## Description

用户要求大面积绿色、简洁登录页、减少标语，以A股投研为主要视觉方向，并使用更易用的开源验证码。参考Dribbble绿色登录页的留白、单一表单与色彩比例，使用原创CSS/SVG装饰，不复制第三方素材。

最终视觉按用户提供的示例重新排版：窄品牌栏、左侧简洁登录、右侧原创等距资料模块SVG插画、白色画布与留白，灰黑及少量紫色，不使用绿色。保留现有全局字体和主题基础色，输入框为示例的简洁底线形式，深色胶囊按钮。无嵌套介绍卡片或流程块，标题“登录你的投资研究工作台”不限A股。配图src/assets/research-isometric.svg为本次原创静态装饰，不是行情数据，不需外链或新增依赖；不新增记住我等会话行为，不影响已登录测试会话。视觉修改运行7项相关前端测试和生产构建，检查桌面与手机。

采用lepture/captcha 0.7.1（BSD-3-Clause）生成四位数字图形验证码，输入与账号密码一并提交即可。ALTCHA已调研，但其HTTPS要求不兼容当前HTTP入口，未采用。无需Key或新服务；校验仍由服务端完成，保留来源绑定、2分钟有效期、限次验证、一次性token及登录限速。

验收：桌面/手机布局简洁；保留密码/飞书登录、认证未开启/加载失败提示与安全跳转；验证码可键盘输入/点击刷新，错误与过期可恢复；不暴露答案，不由前端自行判定通过。验证码成功token仍走既有登录消费流程。
