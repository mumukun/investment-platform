## Description
生产只读抽样出现日线单股事务、WALWrite 等待和排队。用户确认开发后，仅在本地实现日线发布的批量处理。每批按股票数与原始/复权行数有界，批量复核已有凭据，按表写原始事实、价格投影、复权日线、核验及进度，事务提交后再确认事件。仍以成交事实与同口径复权凭据为准。过期输入按单股登记失败；超时或锁冲突走原事务回滚重试，并缩小日线批次。成功但耗时较长的批次不再自动缩成单股。
