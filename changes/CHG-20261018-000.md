# Change: CHG-20261018-000

## Title / Status

波段基础数据完整性、收盘模拟买入及成败复盘。

状态：`READY`。2026-10-18 用户确认清单并明确授权开发完成后直接上线，包含本次需求的正式发布；不包含 marketNewsFeed 或无关工作。

## Description

用户要求先讨论、确认功能清单，再开始开发。原三条选股路径使用
`swing-rules-v5.1.0`；本次保留趋势通道、低位蓄势、突破回踩的形态条件、确认逻辑、
阈值和优先级权重，完善输入数据、结果发布门槛及效果账本。

已确认的业务方向：收盘显示“可计划参与”视为当天已经模拟买入，后续状态变差不撤销；
必需数据未齐时不发布新的正式参与结论；记录有证据的成败复盘，暂不自动调参。
下列具体计价、去重和边界处理作为本次清单一并确认。

### 1. 基础数据范围与补缺

- 使用沪深京 A 股证券目录核对母集合，保留当前证券范围及参与限制，不以788只候选或
  现有流动性历史池代表全市场。基础日线采集不因暂时未命中策略而停止。
- 补齐股票至少最近140个真实交易日的应有日线，供现有至少120根有效日线规则使用。
  上市时间不足时按真实上市历史保存；停牌、未上市和不支持的证券明确记录原因，
  不伪造交易日、价格或成交。
- 必需输入按当前算法实际依赖列明：股票 OHLC、成交额、口径一致的复权历史，
  同期指数基准、行业归属和行业/市场计算输入、证券交易规则及交易日历，
  以及参与确认实际使用的分钟价格、累计成交额和 VWAP。
- 成交量、换手率、概念标签等未参与当前必要条件的字段单独显示可用性；
  不把辅助展示字段缺失误报为整个策略必需数据失败。
- 修复指数历史停在9月9日的问题，检查全部所需交易日，而非只追加最新一个点。
- 核对分钟量比的实际历史样本和字段传递，分别报告原始数据覆盖、指标可计算覆盖；
  不将当前37.9%的字段可用率直接当作原始历史漏采率。
- 复用既有来源及调度进程；增量更新、发现缺口、有限重试并补缺。
  使用已有备用源时保持证券身份、单位、日期与复权口径一致；无法取得的数据保持缺失。

### 2. 自动维护与选股前完整性验收

- 每个交易日按“更新基础数据 → 核对证券/交易日及必需字段 → 计算 → 验收后发布”执行。
  对本轮扫描集合和共同指数/行业输入逐项验证，不以最新日期、任务返回成功或非空率
  单独代表完整。证券目录本身未经完整性核验时，也不能宣布全市场数据齐全。
- 检查应有股票数、应有交易日、有效历史长度、价格/成交额合法性、复权口径、
  指数日期对齐、分钟同时段真实样本以及关键指标是否可计算。
- 单只股票的合法历史不足与采集故障分开列示；沿用既有证券/策略资格规则排除的股票
  有可查原因，不能把应有数据漏采伪装成未命中策略。
- 本轮扫描集合任一必需输入未通过，则本轮整体标记不完整，暂停新的正式名单及
  收盘模拟买入发布；不能静默缩小范围后仍称完整，也不能以旧指数/旧行情冒充当日输入。
- 保留上一次核验通过的快照，明确显示原交易日且只供历史查阅；数据恢复后先重新
  验收，再发布新结果。已存在的模拟交易仍保留，缺少后续结果时等待补齐。
- 复用现有调度，不新增服务、Codex 自动化、付费数据或外部消息通知。

### 3. 数据状态页面与缺口明细

- 页面顶部给出清楚的两种结果：“本轮数据已通过完整性检查”或“数据未齐，本轮选股暂停”。
  正在补采时在未通过状态下显示进度、最近尝试和最近成功时间。
- 提供缺口明细：股票/指数、缺失日期或字段、原因、预期/实际日期、补采状态。
  显示全市场母集合、策略可扫描集合、合规排除、数据不足、实际已评估和候选数量。
- 明确区分“完整扫描后没有合格股票”与“数据未齐，无法完成扫描”。
- 单股详情可查看本次判断所用数据截止日及必需输入状态；页面当前行、总览和详情一致。
- 把“证据置信度”与数据的完整/新鲜验收区分，防止字段非空却日期陈旧时仍被理解为数据健康。

### 4. 收盘模拟买入与5日结算

- 正式样本以当天最终收盘快照及顶层主导路径的“可计划参与”为准；仅白天短暂出现、
  收盘不再满足的，不新建这笔收盘模拟买入。数据验收通过后，统一按当天收盘价记模拟入场，
  不再等待次日开盘，也不依赖下一分钟成交数据证明收盘模拟入场。
- 记录真实生成时间、信号交易日、模拟入场日/价及入选时证据；收盘价是约定的模拟计价，
  不把生成时间或后续补算伪装成收盘前已知，也不执行真实交易。
- 买入日为T日，第0天；之后第5个真实交易日收盘为目标结算点。
  使用交易日历，不以自然日或简单跳过周末计算。记录原始入场/结算价，收益使用一致
  复权口径处理除权除息；暂沿用价格收益，不新增手续费模型、账户或仓位。
- 入场后参与状态变化、跌破原失效位或出现亏损，均不撤销、重置或剔除这笔记录。
  +2R/-1R等过程事件只辅助复盘，不触发主账本提前卖出或提前结算。
- 同一股票在一笔5日跟踪结束前不重复建立样本，多个路径命中也只记录一次买入。
  冻结买入时主导路径，辅助路径保留为标签；按主导路径汇总，避免重复计数。
- 第5日结算后，最早下一交易日收盘仍符合条件时可新建下一笔；重复运行同日任务不得重复记账。
- 每笔效果明细展示第1至第5个真实交易日的日期、有效收盘价和相对同一模拟入场价的
  累计收益率；同时展示入场日期/价和数据截止时间。累计收益不是相邻两天的单日涨跌幅。
  按一致复权口径计算并标明口径；除权除息时不直接混用原始价格计算收益。
- 第1至第4日随着完整收盘数据到达逐日更新，不等到第5日才展示收益。
  尚未来到的日期标“待更新”，已到但缺少行情标“数据待补”，目标日停牌标“停牌”，
  均不填0或复制上一日收益，也不把不足5日的记录提前纳入最终5日胜率。
- 明确标为“模拟累计收益率”，来源为行情与约定模拟入场价；不冒称真实账户收益，
  不增加持仓金额、真实成交或资金账户。第5日仍为主账本正式结算点。
- 效果跟踪从累计模拟买入账本读取，不以当天候选名单、最新参与状态或主列表分页结果
  作为样本全集。默认覆盖观察日及此前5个真实交易日新建立的全部模拟买入记录，
  包含买入日T至第5日结算的完整区间，确保今天刚完成第5日结算的记录也仍可见；
  并保留更早建立但仍未结算的记录。每笔按自己的入场日独立计时。
- 已结算记录长期保留，可按买入日期和结算状态查询，不能在满5日、退出候选池或状态
  变为暂缓/不参与时从账本消失。同一口径的总体统计基于全部正式账本记录；日期筛选
  明确作用范围，汇总和逐票明细的范围及计数一致。历史观察日不展示当时尚未产生的记录或未来收益。
- 5日结果盈利、持平、亏损分别展示；胜率分子只含盈利，分母含已完成且结果完整的全部三类。
- 新口径不再产生“无法入场”的无效样本。未满5日、数据待补的保持待结算，说明具体原因。
  目标结算日真实停牌且无有效报价时单列停牌未结算，保留目标日期，不顺延冒充另一天的5日结果。
- 旧V5.1事件与结果原样保留，不自动改写或批量重算成新口径，不混入新胜率。
  提供旧记录查阅并明确标注口径；历史补建只作为事后重建，不能充当当时生成的实采信号。

### 5. 有证据的成败复盘

- 每笔记录展示：当时入选理由与冻结证据、5日结果、期间可核验变化、可能的成败解释。
- 复用当前算法的结构和关键位定义，记录趋势延续/结构破坏、关键位失守、量能变化、
  同期指数与行业表现以及最大有利/不利波动，并附发生日期和数值。
- 复盘以规则和真实行情事实生成，相关现象与可能解释分开；证据不足显示暂无法判断，
  不编造资金意图或因果，不新增大模型调用。
- 按三条主导路径分别汇总样本数、5日胜率、平均收益/亏损和复盘标签频次；
  低位蓄势保留低位承接、启动站稳、启动回踩入口以便后续比较。
- 复盘只提供研究证据，本次不新增选股过滤条件、不调权、不自动学习。
