## Description

波段、短线、自选在后台逐批计算、保存并展示最近可用结果。已就绪股票不等待全量扫描或收盘补采；更新慢、失败或结果超过几分钟不清空。4 分钟只是用户举例，120 秒仅作性能优化参考，不作展示或开发验收硬门禁。页面保留真实来源/评估日期和时间；新有效事实明确失效时逐股替换，其余最近结果保留。

原公式、阈值、原合格次序和正式尾盘账本保持。历史流动性仅补充待确认观察，不冒充今天金额或原规则通过；短线动量、尾盘超短、波段三种算法身份独立。完整方案含 32 项门禁与 18 组场景：[修复方案](../docs/plans/CHG-20261026-006-intraday-candidates.md)、[算法影响](../docs/plans/CHG-20261026-006-algorithm-impact.md)。
