# Change: CHG-20261106-002

## Title / Status

## Description

未选对比股时只查询列表。已有相同观察范围的曲线时，翻页、筛选、排序复用历史；披露身份变化时重新加载。上游只读取交易日历和上一交易日计算所需的融资余额；Dashboard 跳过仅生成时间变化的快照写入，并保留相同条件的旧快照回退。

## Tests

本地隔离 PostgreSQL 合成 88 个交易日、3,200 只两融股、281,600 条披露。每场景交替查询 9 次，去掉首次后的中位值。空选首屏 78.2 → 52.7 ms，带 8 股对比的翻页 80.8 → 52.5 ms，刷新 8 股曲线 79.5 → 59.9 ms。前后列表、指标、市场及历史覆盖逐项核对通过；保留图表的完整刷新结果相同。Provider 25 项、Dashboard 契约与快照 19 项、页面 17 项及前端构建通过。
