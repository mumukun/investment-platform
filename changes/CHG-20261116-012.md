# Change CHG-20261116-012

## Title / Status

波段个股按批次索引读取并先展示摘要 / RELEASED

## Description

波段候选详情原先读取完整评估压缩包。此次按原评估批次和股票代码查一条。名单和逐股详情在同一事务写入。每个规则版本保留最新三个明细批次，发布下一批时淘汰超出范围的明细，原归档继续供历史读取，沿用现有保留政策。点击候选先打开摘要，简版日 K 独立加载，打开「波段判断」再加载该批次依据和评估记录。

## Tests

- 只读取样生产 2026-11-16 22:17:08 波段 v5.5.0 快照，回放到隔离 PostgreSQL 16。1,215 只的明细逐字段一致。执行计划使用个股主键，返回一行。9 次比较中读取中位耗时由 859.44 ms 降到 6.26 ms。各测 5 次名单与明细发布，写入中位耗时由 1,649.89 ms 增至 2,398.38 ms，包含索引、写入及旧批次淘汰，公共原归档写入在计时前完成。单批新增压缩明细约 12.8 MB，实测只保留 3 批。耗时来自本地回放。
- 前端验证摘要无需等详情、选中批次信息、看 K 线、按需见证据、切换股票与日期时迟到结果不覆盖当前弹框。两组 Vitest 和生产构建通过，新增切股用例也通过。
- 后端 PostgreSQL 验证列表、冷读、旧批次、空股票、原归档保存和自动淘汰。所选后端覆盖共 28 项通过。

## Release Impact and Rollback

已评估兼容性。新增 PostgreSQL 表，原快照、公开字段、策略判断与版本保持兼容。旧快照和较早批次按需使用原归档。Provider 先于 Dashboard。回退可继续读原快照。观察生产写入耗时与额外占用后，才评估将逐股存储作为新批次的归档格式。
