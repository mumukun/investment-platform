## Title / Status

## Description

用户接受普通发版不额外备份、有数据风险时按范围备份，随后授权“提交代码准备上线”。本轮实现并本地提交，按准备模式不安装NAS发布器、不部署/重启、不创建定时任务或开启WAL。

每个仓库条目可声明 `database_backup`：普通无数据影响或兼容新增且旧代码可运行采用skip；数据风险采用tables/full。必填影响分类、旧代码兼容结论、理由与证据。未知影响不能skip或按表；旧计划未声明字段继续全库备份。按表模式只接受精确schema.table，受保护管理员命令通过独立参数传递过滤项并启用strict-names，范围含关联表/序列的责任在Change审查。

skip不执行dump/可读性命令，回执与镜像阶段明确SKIPPED，不伪造文件或备份PASS。镜像续跑绑定原计划及备份决策；兼容代码回退无需dump，显式数据不兼容计划拒绝自动代码回退，执行过的备份仍需原文件完整性核验。SOURCE_TAG_BUILD复用相同策略；保留其原有不支持自动rollback的限制。原身份、锁、健康和smoke不改变。
