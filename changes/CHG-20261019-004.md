# Change: CHG-20261019-004

## Title / Status

## Description

电脑端全部18个现有入口及内部操作适配手机和Pad；复用Vue、Element Plus、公共个股详情和现有API。手机提供完整分组导航，保留筛选、排序、历史日期、全部字段与写操作；表格只在内部横向滚动，弹窗、软键盘与图表触控适配小屏。第二步增加PWA安装、静态资源缓存、手动确认更新与断网提示。

目标设备：iPhone 15 Pro、iPhone 17 Pro Max（Safari及主屏幕模式）、Samsung S24+（Samsung Internet/Chrome）；平板验证横竖屏布局。PWA使用既有含非标准端口的HTTPS入口，家中HTTP/IP入口继续普通H5。缓存与会话按来源隔离；不自动切换到HTTP。不做APK、离线编辑同步或新增系统推送。

用户已授权本地开发，并于2026-10-20明确要求改完后先提交代码、不发版，等待后续其他需求一起开发完成后再统一发布。本轮仅授权本地Commit，未授权Push、PR、Merge、Tag或部署；后续正式发布仍需明确授权。原始checkout中的说明文档和原型图片保持原状。
