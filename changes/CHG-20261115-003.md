# Change: CHG-20261115-003

## Title / Status

短线参与资格、评分及尾盘隔夜模拟重构 / RELEASED

## Description

短线观察 v3 在参与判断中使用同交易时段的有效行情（180 秒），拒绝不可靠的市场/行业基准，确认间隔至少 5 分钟且不跨午休，超过 10 分钟的报价断档重新确认。观察条件可追溯到多个匹配路径。新评分以结构 35、确认 25、结构风险 27 为主，行业 8、历史流动性 5；相对行业弱不再独立否决，行业数据可靠性仍是参与门槛。

隔夜实验在 14:50–14:55 冻结合格名单，14:56 只读取信号之后且在 14:57 之前已收到的报价作理论交易参考。缺证据、涨停模拟买不进、跌停无法确认退出分别统计。五组同窗比较原评分、新评分、弱市空仓、突破位置和不限结构相对强度。费用前次日 +3% 触及 / 收盘、纯收盘收益和扣费敏感性（0.15% / 0.30%）分别展示；全组完整结算才进入板块配对。收盘模拟历史与 CHG-20261115-002 实验结果独立保留。

## Tests

Provider 94 项定向用例通过（含隔离 PostgreSQL），覆盖数据门槛、确认断档、版本协商、信号/模拟参考价时钟、账本隔离与成本计算。看板后端 34 项通过，用真实适配器验证 Provider 同一算法生成的模拟报表和异常样本；受影响前端 25 项、类型检查和构建通过。Chrome 1440 与 390 像素通过真实视口检查，页面无横向溢出；演示为合成行情。

提交前以本机隔离 PostgreSQL 16 和合成行情衡量受影响链路。5,000 只全市场标的、1,500 只合格候选，名单生成并写入用时 39.5 ms，读取 1,292 只报价并写入模拟入场用时 39.7 ms。59 个完整配对日、76,228 个标的日的统计投影重建用时 4.78 秒，读取用时 16.1 ms。样本总数、扣费结果和重复刷新行为均与预期一致。分别低于本地冻结与入场 5 秒、重建 20 秒、读取 1 秒的检查预算。该测试未测 NAS 负载和真实行情覆盖。

## Release Impact and Rollback

依赖 CHG-20261115-002，涉及 stock-analyzer 与 Dashboard，顺序为 Provider → Dashboard。统计用可选字段；新版研究与状态请求显式协商。切换期间旧 Dashboard 保留最近 v2 快照及原日期，缺旧结果则如实标不可用；待新版稳定且无旧客户端后可另行退役兼容。无 DDL、无新增数据商/服务、不改基础数据、原历史账本、波段及 marketNewsFeed。保留上一版本的研究与结算路径作为回退依据。

## Evidence and Remaining Work

三个仓库已分别在本地提交，未推送、未发布。演示位于同工作目录的 evidence/short-tail-demo.html。生产实际尾盘报价覆盖、入场率和净收益尚未验证。新规则先看 1–2 个真实交易日的冻结与模拟入场覆盖；累计至少 20 个可比日且新旧各 200 笔后，联合复核日等权净收益、费用敏感性、净胜率和大亏率。
