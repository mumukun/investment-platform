## Description

恢复资金页因来源迁移丢失的板块主图，扩展成“板块资金与趋势”。用户已确认开发范围及顺序：盘中在前，近期在后。

- 盘中保留主图、右侧标签、筛选、关注和研判；目录和当前曲线分离，不再只允许默认Top12。行业目录分页校验后按代码任选，最多同时比较24条；旧名称关注可迁移为代码，历史缺失关注不静默删除。
- 新浪全市场资金为独立参考，来源、数据时间与板块分别展示，不合计、不拼接。自定义曲线选择不覆盖默认每日归档，源失败保留当日有效曲线并标明陈旧。
- 近期模块独立加载，支持3/5/10个已收盘交易日净流入、涨幅、流入天数、资金强度、MA20距离及五日方向；可搜索/筛选/排序/分页，详情为日K、MA20、日资金柱图及支持/反向证据，并可返回盘中。
- 初版可解释规则区分资金积累观察、同步走强、上涨流出、流出承压、方向待确认、数据不足与陈旧；不证明机构意图，不输出胜率或交易指令。
- 首版完整范围为东方财富行业目录（含不同层级），非概念全集；2026-10-16实际分页核验5页496条，不硬编码条数，不合计重叠板块。盘中价格确认、宽度、核心股及异动通知恢复不在本次范围。

产品说明：[板块资金与趋势](../../investment-research-dashboard/docs/product/sector-fund-research.md)。
