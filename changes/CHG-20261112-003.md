# Change: CHG-20261112-003

## Title / Status

减少选股接口结果重复写入与限制盘中评估历史 / RELEASED

## Description

关联 [CHG-20261112-002](CHG-20261112-002.md) 和 REL-20261112-001。生产
`api_read_projection` 实测 21.02 GiB，现存载荷约 1.38 GiB。旧版波段结果在
90 分钟内重建 33 次，每份约 12.7 MiB。

- V3 波段按业务输入修订决定是否重建，忽略验收检查时钟，保持原行情时间、失败降级与接口契约。
- 06:15 复用 stock-watch 调度，保留最近五个有结果交易日的完整评估。较早日期仅清理已完整收盘且尾盘已冻结的未引用中间批次，保护最新收盘、冻结批次及交易引用。
- 清理默认只读预览。应用模式复用近期可读备份回执，分事务最多五条，单次最多八组，最多启动一分钟内的批次。生产收缩单独维护。

## Release Impact and Rollback

仅 stock-analyzer 需发版。无 API 契约、采集频率、评分或数据库结构变化。生产删除以现有备份为恢复点；切回旧应用版本无法恢复已删的可淘汰评估。
若授权在同一发布窗口收缩，在精确版本验证通过后，独立备份目标表、验证可读性、暂停访问该表的进程，并持 NAS 全局维护锁执行单表收缩。恢复后核对健康、当前和历史波段、买入依据及结算记录，再测量实际磁盘回收。
