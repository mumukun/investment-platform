# Change: CHG-20261021-001

## Title / Status

X Watch 飞书第二群与 Discord 可配置 @指定用户。RELEASED；业务 PR #10 已合并，正式发布 REL-20261021-001 成功。

## Description

用户希望 X 信息推送到指定飞书群时 @本人。目标群匹配现有第二个 X 推送通道。
增加可选 `X_WATCH_EXTRA_FEISHU_MENTION_OPEN_ID`，只在该通道的卡片顶部添加用户 mention。
空配置维持原行为；拒绝 @all、多人列表和非法 ID。沿用各目标独立重试，不另发提醒消息。
用户随后要求 Discord 频道也 @本人并提供用户 ID，追加可选 `X_WATCH_DISCORD_MENTION_USER_ID`。
Discord 使用消息正文的用户 mention，保留原 embed；allowed_mentions 只允许配置的用户，关闭角色和全体解析。
空配置不添加正文 mention；配置校验拒绝非法 ID、多人列表及 mention 标记。
用户追加办公场景下的中性标题要求：飞书卡片标题统一为“信息提醒”；Discord 的发送名称、作者和卡片标题同样中性化，移除页脚固定的 X Watch 标识。
保留来源账号于卡片正文/页脚、原文链接及定向 mention。飞书机器人应用名称、群名、系统通知预览不由这些消息字段控制，未修改外部应用配置。
不将真实用户 ID、群 ID 或凭据写入源码、测试和治理记录。
