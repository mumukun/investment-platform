# Change: CHG-20261105-006

## Title / Status
波段模拟跟踪完整历史查询提速 / RELEASED（REL-20261106-001）

## Description
完整历史抽屉调用 Dashboard 代理的 history-v3，当前规则最多请求 20,000 条。提供方原先按最早买入日至观察截止读取所有命中证券的行情，并对每笔记录重复扫描整个状态事件、停牌集合。优化为按买入及随后的五个交易日读取所需证券日期，按股票索引停牌和状态，普通全历史先按 SQL 限额取样并保留全量计数。筛选、排序、收益结算、规则版本及响应结构保持原口径。

最近买入的展示另行确认。建议跟踪中显示买入时间、已更新进度、最近一期累计收益及预计 T+5 日期，已结算显示 T+5 结果，完整五日明细保留在展开行或历史抽屉。

用户确认停用旧版历史。Dashboard 移除旧版入口、账本切换及相关提示，完整历史与近期记录继续按当前规则查询。保留既有历史账本和兼容接口。

用户确认两种策略统一默认范围。短线和波段按共享交易日历查询截至观察日最近五个实际交易日的买入明细，较早未结算记录也仅在完整历史中展示。胜率和效果汇总独立统计截至观察日的全部历史。
