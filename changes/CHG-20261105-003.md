## Description

接续已发布的 CHG-20261103-003 与 CHG-20261104-001。11 月 4 日、5 日原实验因行业基准缺失，84 / 172 只可计划参与股票全无评分，但其同板块基准行情均具备。用户确认采用同板块两因子和按入选日对照。

- 仅为原短线可计划参与候选计算新版实验分，板块内比较五日超额与领先天数，等权分组。旧评分留档保留。
- 收盘冻结同板块实验高分组与原评分等量组，附原候选全组。以同一批次模拟账本的已结算样本计算胜率，区分入选、入账和结算。
- Dashboard 按入选日与板块展示对照，逐股名单复用观察日期和分组筛选。
