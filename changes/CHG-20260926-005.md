# Change

## Change ID

`CHG-20260926-005`

## Title

波段候选参与优先级评分与列表排序

## Status

`READY`

## Description

在不新增“今日 Top”等页面模块、不改变四态参与门禁的前提下，为“可计划参与”候选生成透明、
可拆解的参与优先级分，并在现有候选清单内按分数降序展示。固定策略路径顺序和股票代码不再作为
可计划参与候选的业务优先级依据。

范围包括：

- 仅在现有硬门禁全部通过后计算参与优先级，评分不能覆盖暂缓、禁追或不参与结论；
- 使用当前规则已有的结构相对质量、板块协同、ATR 风险效率和数据完整度生成 0～100 分及分项；
- 同一股票多路径独立评估，主导路径优先选择已确认且评分更高的路径；
- Dashboard 保持现有页面结构，在候选行和详情中展示总分、分项与解释；
- 保留旧 V3 历史快照可读，缺少新增字段时明确显示未评分，不伪造为 0 分；
- 使用现有 5/10 日 outcome 账本为后续权重校准保留可追溯的 `rules_version`，本 Change 不宣称分数是上涨概率或胜率。
- 完善现有“效果跟踪”卡片：明确正式信号、可交易结算、不可交易和待结算口径，所有比率展示分子/分母；
- 接通现有 history-v2 账本，支持从 5 日正收益、+2R 路径、次日深回撤及各策略路径下钻到具体股票；
- 状态事件向后兼容保存 `participation_decision`，新事件以“可计划参与”作为正式信号事实，历史空值按原确认状态兼容读取。

非目标：自动交易、仓位建议、固定 Top N、A/B/C 档、生产部署、基于历史样本自动训练权重。

验收标准：多个“可计划参与”候选按参与优先级分降序返回和展示；非可参与候选不能通过分数越级；
同分不按股票代码区分业务优先级；用户可查看每个分项及排序原因；Provider 与 Dashboard 契约和测试同步通过。

## Dependency Impact

`stock-analyzer` 是评分和排序的唯一 Provider，`investment-research-dashboard` 只消费并展示结果。
实现和验证顺序为 Provider → Consumer。`marketNewsFeed` 不参与。

## API Impact

`GET /api/integrations/investment-dashboard/swing-selection` 的
`investment-dashboard-swing-selection-v3` 项目将向后兼容增加可空的参与优先级总分、分项和解释字段。
认证、状态码、分页、日期解析、freshness 与 last-known-good 语义不变。

`investment-dashboard-swing-stats-v2` 向后兼容补充分子、分母、待结算和不可交易计数；Dashboard 新增
`GET /api/v1/swing-selection/history` 只读代理，消费现有 `investment-dashboard-swing-history-v2` 的事件、
结果及兼容新增的规范化 `samples`。

## Database Impact

对 `swing_state_event` expand-only 增加可空 `participation_decision`。不删除、不回填或改写历史事实；
历史空值继续按原确认状态兼容读取，新的正式信号会保存当时的参与决策。

## Contract Impact

- `contract_version` 保持 `investment-dashboard-swing-selection-v3`：新增字段可空且 Consumer 容忍缺失，属于兼容性扩展；
- `investment-dashboard-swing-history-v2` 和 `investment-dashboard-swing-stats-v2` 仅增加可选明细/计数字段，不删除或重解释既有字段；
- `rules_version` 由 `swing-rules-v5.0.1` 升级，隔离新的评分权重与排序语义；
- Provider 模型、Dashboard integration 模型、TypeScript 类型、fixture、契约文档和回归测试同步更新；
- 旧 V3 快照缺少评分字段时返回 `null`/未评分，不补造数值。

## Compatibility Strategy

Expand-only。先发布能返回新增可空字段的 Provider，再发布能消费并展示字段的 Dashboard；旧 Consumer
会忽略额外字段，新的 Consumer 对旧快照使用未评分降级显示。无字段删除、重命名、单位或时区变化。

## Feature Flag

Not required。评分和效果明细只改变研究排序、解释与只读统计；新增状态事件列为可空的 expand-only 事实字段，
不改变硬门禁、状态机或外部写入；回滚可由应用版本完成，保留该列不影响旧版本。

## Release Impact

两个业务仓库均为向后兼容 MINOR 功能变更，纳入 `REL-20260926-001`；最终版本号由该 Release Manifest 冻结。
发布顺序：`stock-analyzer` → `investment-research-dashboard`。Provider 发布时必须将
`SWING_ENGINE_RULES_VERSION` 配置为 `swing-rules-v5.1.0`；新分数只在响应规则版本与实现版本一致时启用，
避免旧规则快照被错误标记为新评分。Provider 启动时以幂等 DDL 增加可空
`swing_state_event.participation_decision`；不回填、不删除历史数据，不涉及 Feature Activation。

## Rollback Strategy

回滚两个应用到各自上一稳定不可变版本。Provider 回滚后 Dashboard 将新增字段视为缺失并显示“未评分”；
Dashboard 先回滚时旧页面会忽略 Provider 的新增字段。任一端出现契约拒绝、排序越级、日期安全或
last-known-good 回退异常时停止发布。数据库新增列保留，不做破坏性回滚。
