# Change: CHG-20261109-006

## Title / Status

修复波段结算误判复权凭据缺失 / RELEASED（REL-20261109-002）

## Description

波段已支持复用复权核验，且以五日有效收盘价结算。最新一份凭据失效或覆盖不全时，原实现可能忽略其他仍能证明买入日和对应持有日价格同口径的凭据。改为逐持有日查验符合条件的凭据。确无有效核验、缺收盘价或停牌时保留现有待完成语义。缺最高价时继续正常结算收益，相关盘中路径指标留空。
