# PostgreSQL查询优化验证

## 范围

只修改stock-analyzer短线量比的历史分钟读取与两个调用方；无DDL/新增索引/数据库配置/历史数据删除/契约字段或规则版本变更。以759c9c9为代码基线，本地预留PATCH 4.4.1，未提交/推送/合并/部署。

生产诊断使用只读元数据、现有查询EXPLAIN（不带ANALYZE）及活动查询类别采样；未在生产运行新SQL或性能压测。采样看到历史poll_history查询约0.8～1.8秒执行，其中存在并行worker和IO等待。无pg_stat_statements，不能把全部历史临时写入归因到本查询。

## 本地等价与回归

隔离Docker容器codex-pg-query-chg011-db，PostgreSQL 16.14，数据库chg_pg_query_011，仅127.0.0.1开放随机端口。测试使用会话临时表、合成行情、既有主键和日期/代码索引，不含生产数据。

`SHORT_HISTORY_TEST_DATABASE_URL=<本地测试库> python -m pytest tests/test_short*.py -q`：102 passed，16 skipped。65项真实PG测试覆盖空历史、严格日期上界、全局交易日窗口（目标股在最新交易日缺数不偷偷向更早日期补齐）、重复代码、未指定/空代码列表、精确分钟/无记录分钟、空成交额、无效close及最小样本数。两个运行时入口确认只读取实际计算分钟。

16项跳过为既有short_tracking可选数据库集成，未修改其收盘账本功能。`python -m compileall -q stock_analyzer scripts tests`、`git diff --check`通过。
