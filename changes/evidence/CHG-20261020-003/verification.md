# CHG-20261020-003 验证记录

本轮只进行本地修改、隔离验证与Commit，不Push/PR/Merge/Tag/部署/生产补数。Provider与Consumer工作树来自重新核实的生产精确SHA；未合入此前移动端/曲线需求。以下证据明确区分真实来源与模拟。

## 根因

- 实时报价的QUOTE_PROVIDER=tencent没有控制波段维护日线；后者写死新浪→AKShare东方财富qfq，来自88130a6。
- 10/20新浪当日日线尚未发布，东方财富备源连接失败。维护连续12次失败后结束；指数已有当天数据，但参与个股均缺当天日线，因此新结果被门禁拦截。当前生产身份仍为stock-analyzer v4.4.2 / 5b1a7ff，Dashboard v0.28.2 / 98b7e67。
- 页面把未齐任务显示为“正在恢复”，并将历史报价0/0误报为实时行情降级，掩盖真实进度。

## 修复决策

用户授权由开发方在腾讯、新浪之间决定，不扩大来源。新浪作为含真实历史成交额的主源；新浪延迟/失效或旧错误批次价格需重试时，腾讯提供整个前复权价格窗口。历史成交额按日期来自新浪或已归档的新浪/腾讯，腾讯当天金额只接受同证券同日收盘后、OHLC匹配的原始报价万元字段×10000。禁止成交量估算、未复权替代、晚日期冒充目标日、未知来源金额混入。双源无法满足时保留明确缺口与最后有效数据，不降低门槛。

波段相关requests及AKShare直连，忽略环境和Session代理，东财域名在传输前拒绝（重定向同受约束）。删除其自动停牌/F10修复采集，历史分类/停牌事实保留。北交所沿现有仅观察规则，不纳入沪深日线补数任务/失败计数，证券母集合及健康排除记录不变。其他业务来源模块及未发布需求不修改。

集成测试还发现：同秒写running→terminal导致swing_reference主键冲突。仅其持久化观察时间改用微秒精度，无DDL/迁移，页面时间和规则版本不变。
