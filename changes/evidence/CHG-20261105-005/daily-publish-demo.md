# 日线写入本地模拟

同一台 Mac 的本地隔离 PostgreSQL，回放同一批 200 只股票。每只先有 140 个交易日，下一日有 190 只走增量，10 只走全窗口。外部行情由固定数据模拟，三组从相同状态开始。

| 写入方式 | SQL 调用 | 事务提交 | 本机写入耗时 |
| --- | ---: | ---: | ---: |
| 旧版退到单股 | 2,980 | 200 | 5.652 秒 |
| 旧版每批 8 只，批内逐股执行 | 2,630 | 25 | 3.302 秒 |
| 新版批量查库及写表 | 182 | 13 | 0.948 秒 |

三组各有 28,200 条原始事实、28,200 条原始日收盘和 28,200 条前复权日线。原始及复权事实、核验、入库状态、T+1 至 T+5 逐股累计收益对比一致。表中 SQL 调用为客户端执行次数，事务提交另行计数。模拟脚本及原始输出在 /private/tmp/CHG-20261105-005。

Mac 耗时仅记录本轮模拟环境。NAS 上的吞吐、排队时间和 WAL 等待尚未测量。
