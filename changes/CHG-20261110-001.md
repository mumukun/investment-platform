# Change: CHG-20261110-001

## Title / Status

保障盘中核心行情和选股链路 / RELEASED（REL-20261110-001）

## Description

科技和行业指数报价独立于成分、日线和历史计算。分钟同步只传指数与报价，
按源时间更新当前比较，不改写详情和历史。移除闲置的新浪科技概念运行链路，
保留策略分类与已存历史。减少相同候选状态写入，修复旧短线成交额 SQL。
盘中保留个股、选股、板块和天梯，非核心批次错峰执行。
