# Change: CHG-20261116-004

## Title / Status

超跌反弹每五分钟结合个股行情筛选 / RELEASED

## Description

交易日连续竞价期间，每五分钟使用当日 OHLC 报价及前 80 个核验日线更新全市场候选，并以此前 20 个完整交易日的成交额核验流动性。符合条件的个股可在盘中显示参与状态、评分、区间与失效位。页面显示盘中评估时间、行情时间及覆盖。过期或缺失报价不能得出当前参与结论；缺上一日策略快照时仍可按基础数据筛选。盘中信号与正式收盘结果、模拟成交研究分开保存。

当日观察跨轮次保留。全市场两轮之间按后台现有约 15 秒节奏，仅批量检查已入围个股，遇到较新的有效报价重新评估。忽略当天累计成交额，包括该字段缺失。

本次在干净基线上验证，CHG-20261116-003 的本地列表字段需求独立保留。
