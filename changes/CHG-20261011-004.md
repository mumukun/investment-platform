## Description

同一对话内用户继续授权：缩短字段解释并改用易懂语言，各模块表单默认采用成熟组件库，修复蓝色效果统计下钻空数据，完成后本地启动验收。

- 导航按市场与机会 → 选股与决策 → 跟踪与复盘 → 资料与管理分组。美股紧随驾驶舱、板块置于席位前；保留路由、开关和认证条件。
- 字段说明先显示含义、怎么看与例子，常用字段用普通语言，公式与枚举按需展开。
- 沿用已安装的 Element Plus，迁移剩余原生输入、下拉、日期、文本域和复选框；统一中文 locale、搜索下拉与清空体验。后续表单默认规则写入 Dashboard AGENTS 与技术文档。
- 根因：history 先分页普通事件再过滤正式信号，观察事件挤掉正式信号；事件与结果分别分页也可能无法关联。Provider 改为先筛选正式信号、按股票/日期/路径取最早事件，再分页并按 event_id 关联结果。保留原始 events/outcomes 兼容行为。
- Consumer 按点击路径及汇总 rules_version 请求明细，校验契约与版本，保护并发请求；不一致时提示异常并可重试。收益、路径和回撤分类只计可交易已结算记录。
