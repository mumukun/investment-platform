# Change: CHG-20261116-013

## Title / Status

短线与波段观察池筛选和计算优化 · RELEASED

## Description

短线采用 `short-observation-v4`，波段采用 `swing-rules-v5.6.0`。使用证券规则、已核验历史流动性和缓存特征做前置筛选。短线要求近 20 个已完成交易日日均成交额至少 7,500 万元，各路径的现价区间收窄至关键位 −0.35 至 +0.75 ATR。突破路径检查现价与 MA20 方向。均线承接增加 MA10 ≥ MA20，并要求当日低点触及该关键位或现价到该关键位的距离 ≤ 0.35 ATR。任一合格路径可保留该股票。波段分别检查趋势连续性和单日脉冲、量能改善证据、MA20 与回踩低点。每轮保留市场覆盖，合格路径才读取确认依据及执行完整评估。保留当日退出事件和缺数时最后一次观察依据。

看板按原评估批次展示活跃观察候选、筛选统计、数据待齐和可检索的退出记录。字段通过现有精简名单和旧完整接口增量传递。模拟交易使用已有账本和结算规则。市场、行业及短线强度基准沿用原样本范围。

## Release Impact and Rollback

本地开发交付。若另行进入发布阶段，可用 SHORT_OBSERVATION_RULES_VERSION=short-observation-v3 保持旧看板兼容，待看板支持 v4 后选择交易日边界切换策略。波段旧规则仍可通过现有配置读取。线上切换宜避开当日尾盘冻结，旧规则确认及效果账本保留按版本回查。回滚使用此前的已核实应用版本和规则，沿用原账本。无需数据库迁移。

## Evidence and Remaining Work

上一版草案的合成对比中，短线 2,750 → 2,200 只，历史准备调用 11,000 → 8,800（两轮）。波段 4,400 → 1,100 只，完整路径评估 13,200 → 1,100。两份合成样本中剔除的旧版可参与记录数均为 0。样本构成由固定场景决定，结果不能代表生产分布。短线热缓存 Python 评估耗时 555.9 → 490.3 毫秒，波段路径循环 804.4 → 152.1 毫秒。内部计时不包括数据库、API 网络读写、压缩持久化和完整后台整轮。

11 月 16 日 22:14 的留档投影可复算有效候选的路径及流动性门槛。同批次旧规则有 1,049 只活跃候选，原 v4 草案有 986 只，叠加本次门槛后剩 664 只，比原草案少 322 只（32.7%）。[留档快照复算](evidence/CHG-20261116-013/short-gate-replay-20261116.json) 的范围为当时的活跃名单。独立尾盘冻结信号的留档缺少时点成交额，整轮延迟、端到端读写量及冻结信号留存率未实测。

本地合成预览 `npm run demo:short -- --port 5213`，分别访问 `/short-selection?observationPool=1`、`/swing-selection?observationPool=1`。
