# Change: CHG-20261113-001

## Title / Status

08:05 早间新闻、美股隔夜 5 日趋势与 DeepSeek 模型名统一 / RELEASED（飞书渠道待接入）

## Description

- 美股快照按美股交易日历在常规收盘后约 15 分钟生成并提前同步，识别冬夏令时、提前收市及休市。美股隔夜映射页在摘要下方展示最近五个美股交易日的代表 ETF 当日收盘涨跌幅，含 SPY、QQQ 参照。同日快照去重，缺值标为待更新。
- 每个 A 股交易日（周一至周五，遇休市跳过）北京时间 08:05 推送同一份简报。使用两个看板现有目录和最近五个交易日的当日涨跌幅覆盖全部板块，简报突出趋势变化并附代表个股、代码和当日涨跌幅；展示名省略「国证」前缀。附美股隔夜同向或背离信号，缺少美股数据时照常发 A 股部分并标记状态。07:45 检查美股快照并按需补同步。首版从行情和现有映射生成。
- 飞书 MK 工作群使用现有应用机器人发「早间新闻」卡片，正文用「今日关注」，避免「盘前」字样。Discord 指定频道使用 Embed。接入时核对飞书群和机器人权限、Discord Webhook 与目标频道的绑定。发送凭据在部署环境管理。
- Dashboard 和 stock-analyzer 的默认值、部署模板及生产模型变量统一为 `deepseek-flash`。涉及 `DEEPSEEK_MODEL`、`LLM_MODEL_FLASH`、`LLM_MODEL_PLUS` 和 `LLM_MODEL_MAX`，沿用现有官方 API 端点及凭据。
