# Change: CHG-20261126-003

## Title / Status

统一波段、短线、超跌反弹模拟入账与对账 / RELEASED（REL-20261127-001）

## Description

接续 CHG-20261120-002 的「今日复核」。用户确认采用同股跨日独立入账。同一机会从首笔买入后的 T+1 至 T+5 内可参加当日正式收盘复核。复用已发布日线、交易规则及复权证据，按原区间、失效位、风险距离、当日可交易价格和截至当日的 20 日均额判断；达标后以当日收盘价独立入账。同股同日一笔，独立新确认优先。延续买入关联原机会，复核期限从首次入账日起算。

每笔沿用 T+1 收盘胜率与 T+1 至 T+5 独立跟踪。跟踪页按笔显示，并可打开各笔明细。旧快照继续读取原记录。此次使用现有业务快照存储与兼容的可选 `continuation_of` 字段，无需数据库迁移和历史回填。收盘初评、晚到日线和截止规则沿用现有实现。复核只读基础事实，写入选股业务快照。

追加模拟跟踪筛选，参考波段完整历史。可组合日期、股票、结算口径、五日有结果、五日正／非正收益、+2R 成功、-1R 失败、五日未触发、次日深回撤、待结算及未入场。按当前快照全部记录筛选后分页，关联汇总使用整批筛选结果。新增可选 `days[].low_pct` 使用同一复权买入基准；最低价缺失的历史仍可按已有 T+5 收盘结果筛选。五日有结果指 T+5 收盘收益已记录，次日结算继续沿用超跌反弹口径。

用户确认开发短线正式五日跟踪。保留截止前完成且市场覆盖就绪的最近有效尾盘评估，使用有新鲜报价证据的「可计划参与」名单。收盘后核对当日行情，优先当日收盘参考价，无有效收盘证据时采用保存的尾盘参考价。收盘涨停记录为无法确认可买入。使用已发布交易日历和同源复权凭据保存每笔 T+1～T+5 收盘、最高和最低收益。T+5 收盘扣一次 0.15% 往返成本计算净收益，+3% 为触及标记。T+5 停牌、收盘跌停和缺数据单列，保留原目标日期。新增只读查询和看板入口，按买入日期、股票代码和五日结果筛选并分页。隔夜实验和历史统计保留各自入口。

用户确认以波段为基准共享入账基础逻辑。三套策略共用每策略同股同日去重、名单冻结、逐笔入账、状态汇总和跟踪交易日计算，保留各自选股与收益统计。波段沿用现有尾盘收录和收益记录；超跌反弹沿用正式收盘复核与次日胜率；短线正式入账走周期对账任务，独立于 14:56 隔夜实验。有效名单零候选、缺少名单、待核验、已入账及有原因未入账均可核对。晚到证据补齐原日和原笔记录。三套策略只读基础事实，在业务投影和原账本写入，无新增行情源或数据库迁移。

追加统一取价和最后一轮资格验收。三套策略共用先取有效收盘价、再取冻结批次内有效尾盘参考价的处理逻辑。短线最后一轮有效评估替换整份名单，早一轮达标、最后一轮降级的个股不入账。超跌反弹以正式收盘复核为资格门槛，等待或定稿前缺证据的候选单列，不混入冻结名单。超过既有定稿截止才到达的证据不回写当日正式账本。看板标明实际采用冻结尾盘价的成交假设。

整体回归发现波段原先会把同日盘中快照当成收盘价。用户确认修复。波段与短线共用来源时点校验，只将交易日 15:00 起产生、入账时已收到且价格和成交额有效的行情作为收盘参考。缺证据使用原冻结尾盘参考价，两种价格都缺时列为待核验；已有账本价格保持原记录。本次追加代码只涉及选股服务及本 Change，本地看板沿用已有对账界面。

用户追加波段模拟跟踪阅读布局优化。最近已结算、跟踪中与新买入默认收起，各组标题常显范围与笔数，可独立展开和收起。完整历史及按买入日的逐笔明细仍可访问。该追加仅涉及看板展示。

追加整理波段「最近模拟买入」和完整历史共用的抽屉筛选。查询范围、日期、代码、规则版本和结算口径分组对齐，结果筛选占独立行，汇总位于表格上方。收益说明按需展开，小屏日期弹层用单月视图。查数、分类、分页和结算逻辑沿用现有入口。

追加统一三套模拟买入列表的逐日累计收益展示。正值用小字号行情红，负值用行情绿，零与缺值保持中性色。T+1～T+4 用常规字重，T+5 有数值时加粗，桌面表格、手机卡片和对应逐日收益明细使用同一方向语义。此处仅涉及看板展示。

用户追加统一三板块的模拟跟踪首屏。默认按实际买入日倒序展示最近五个有入账的交易日，支持切换全部记录。四项汇总基于所选范围和筛选后的全量记录，短线采用五日净收益，波段五日平均收益汇总收盘计价笔数，超跌反弹采用已到 T+5 的收盘结果。波段分组与详细统计折叠，完整历史筛选保留。选股服务增加向后兼容的短线范围参数和波段汇总字段，收益、入账和调度沿用原账本。先提供[合成界面预览](/Users/znkj-mac-0005/.codex/visualizations/2026/11/26/01a2180e-b806-7fe3-88e4-746ef1b80166/simulation-tracking-layout-preview.html)，随后本地开发。

用户追加三套模拟买入提前确认路径。波段、短线和超跌反弹按每笔冻结的买入价、失效价及 T+1 到 T+5 的连续已核验最高最低价判定。首次触及当日可显示成功或失败，同日双触记 −1R，前置日缺证据暂缓，五日未触发凭完整五天确认。短线新增保存当时入场区间下限作为结构失效价，旧记录缺值时不推算。波段已结算统计继续使用原五日分母，超跌反弹原次日结算及三套五日收益规则保留。清单和分类按各自账本展示，无迁移或回填。

原本地临时编号与独立「超跌反弹今日复核」Change 撞号。本轮重新编号为 CHG-20261126-003，沿用原本地工作区，并对齐最新的选股和看板主线，其中已含 CHG-20261126-002 盘后修复。该修复的正式发布状态独立管理。
