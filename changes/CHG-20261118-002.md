### 追加反馈：午休连线（2026-11-18）

### 超跌反弹列表区分当日候选与历史判定（2026-11-18）

复用本轮 Change 和 Dashboard task worktree。用户确认沿用现有列表样式，并要求基于实际历史数据演示。观察日前的禁止追高记录在没有当日有效计划时退出当前候选和计数。全部候选可按名称或代码搜索历史结果，单独显示原判定日期及当日无新评估。仍在观察且当日缺有效评估的候选显示待核验。保留当日判定和有效计划，个股详情通过原事件 ID 读取历史原因、评估价和状态。只改 Dashboard 展示与相关文档。无上游、策略、数据库或契约结构变动。

本地预览用生产只读获取的华峰测控（688200）单股记录及最近 20 根日线。快照生成时间为 2026-11-18 17:21:11（上海）。原判定日为 11 月 5 日，评估价 236.00 元，11 月 18 日独立展示报价 217.30 元。仅单股演示，计数不代表全市场。真正的列表页在无查询时不列旧记录，输入 688200 后找到它，展开个股详情可以回看原状态。无新策略判断或行情生成。

验证：Dashboard `npm test -- src/views/ReboundSelectionView.spec.ts` 9 项通过。新增回归覆盖历史搜索、旧记录不计数、按事件 ID 读取详情、待核验、当日评估和有效计划。 `npm run build` 通过。浏览器在实际 Vue 列表确认候选数为 0，搜索后显示今日无新评估，个股详情可见 11 月 5 日判定和 236.00 元。[本地历史回放](http://127.0.0.1:5217/rebound-selection?replay=history)（`npm run demo:rebound`）。实际历史样本的列表截图仅保留在本地。
