席位订阅与复盘：每日公开动向、资金趋势与 AI 研判

## Status

## Description

用户希望席位名称支持下拉搜索，并查看每天的席位数据，包括未上榜日。已核对当前页面为
普通文本查询，Provider 使用 AKShare 的龙虎榜营业部目录/历史明细，只能提供公开上榜记录。
用户进一步明确只希望追踪一些热门席位。本次范围调整为东方财富公开龙虎榜数据上的
热门营业部关注与每日公开动向；不能用缺失填零或推测实际买卖。

用户已明确确认“开始开发吧”。本记录保存已接受的首版范围；业务 PR 已通过 CI、合入 main 并安全清理任务分支；治理收尾与统一发布准备进行中，未发布。
首版围绕少量自主订阅、每日公开动向、近期资金/选股趋势、案例复盘与可追溯 AI 研判设计。
复用既有数据获取、报表与 AI 能力；本次不以非上榜日完整成交流水为前提。

## Accepted Product Scope

### 产品定位与页面

模块名称：席位订阅与复盘。主路径：我的关注 → 当日公开动向 → 席位详情 → 案例复盘/AI 研判。
页面为四个入口：关注日报、席位详情、复盘记录、订阅管理。默认最近交易日，显示实际数据日期。
首版服务当前私人 Dashboard 的订阅配置，不引入新的多租户身份系统。

### F1 自主订阅与别名管理

- 按营业部名称/代码搜索，下拉展示准确名称与稳定代码；自行关注、取消、排序、备注。
- 订阅保存在服务端，刷新、重启和换设备使用同一 Dashboard 时保留。
- 初始目标：紫阳东路、炒股养家、方新侠、章盟主（用户输入张盟主）、北京知春路。
- 营业部为事实主体；人物别名为可维护分组，一组可关联多个营业部。展示来源、有效期和
  核验状态，不将分组内所有交易断言为某个人的操作。未经核验的别名关联不自动启用。
- 同一营业部重复加入、属于多个分组时，汇总去重；取消关注保留已生成复盘记录。
- 搜索目录可包含其他营业部，持续跟踪与自动日报仅针对已订阅对象，无全市场排行榜首页。

### F2 每日公开交易日报

- 盘后按交易日自动刷新订阅对象，支持手动刷新、日期回看；有限重试，展示最后成功时间。
- 所有订阅对象始终显示。状态区分有公开记录、已检查未发现公开记录、待更新、失败、旧快照。
- 展示股票、公开买入/卖出/净额、上榜原因、披露周期、来源与数据时间；金额缺失显示未知。
- 日报突出新增公开买入记录、公开卖出记录、同股多席位参与和板块变化，点击展开明细。
- 单日榜、多日累计榜和周期不明记录分别标注；多日榜不拆分伪造每日金额。
- 按源记录身份去重；重叠周期不可直接累加。不可确认的记录保留明细并从可比汇总排除，
  同时显示排除数量/金额缺口。只有明确单日口径记录进入每日资金图。

### F3 近期公开资金趋势

- 近 5/20/60 个交易日及自定义观察区间；展示买卖柱状图、可比公开净额和累计公开净额。
- 对照前一等长窗口展示公开净额、披露活跃日数、参与股票数和集中度的变化。
- 无披露日显示无记录而非零交易；来源失败显示缺口。累计值仅表示可比较已披露样本累计。
- 结论展示样本范围、来源覆盖和多日榜排除量，不命名为真实资金余额、持仓或实际收益。

### F4 选股/板块趋势与关注席位对照

- 最近重点公开净买/净卖股票、重复参与股票、各板块公开买入占比及新旧窗口对比。
- 区分窗口内首次披露买入与真实建仓；展示同股公开动作时间线。
- 以已知行情比较股票规模、成交活跃度、价格趋势/位置；缺少字段时明确缺失。
- 对照已订阅席位的同股/同板块买卖方向，描述一致或分歧，不推断协同操作。
- 板块/概念有归属时间与来源；历史归属未保存时不将当前映射描述为当时已知事实。

### F5 案例复盘与学习

- 从每日事件进入案例，展示披露动作、当时可取得的行情/板块背景及后续公开动作。
- 展示披露后 1/3/5/10 交易日价格表现，定义为披露后股价表现而非席位收益。
  有行情覆盖时显示期间回撤；未到期、缺失行情分别标注，不填零。
- 案例覆盖上涨与下跌、活跃与不活跃阶段；按营业部、日期、股票筛选。
- 用户可收藏案例、记录自己的判断与学习笔记；行为特点展示样本量和观察窗口。
- 净额和间断公开记录不用于估算真实仓位、成本、持仓时间、打板价或利润。
- 人物原始公开观点的收集/出处核验作为后续版本，不让 AI 编造本人理念或原话。

### F6 AI 解读、趋势情景与结果回看

- 用户点击生成单席位分析或关注日报综合分析；生成前展示范围，复用相同数据的缓存。
  首版不默认定时调用付费模型。
- 输出固定分为事实、行为解读、可能情景、支持证据、反证、后续观察条件和数据局限。
- 单席位解释近期资金与选股变化，综合报告比较已关注席位；每项核心判断能定位日期/股票记录。
- 情景包括延续、分歧、转弱，使用定性条件；首版不输出未经校准的上涨概率或目标价承诺。
- 保存分析时点、输入数据快照/版本、模型与提示词版本；新增数据生成新记录，不覆盖旧判断。
- 分析记录后续关联实际行情与公开动作，支持用户标记符合/部分符合/不符合/未到期。
  首版为证据对照，不把用户标记当作量化模型准确率。
- 仅对数据充分且可用的范围生成；失败席位不伪装当前数据，不因局部缺口中断全部日报。

### F7 站内更新与质量说明

- 日报更新状态、新数据标记及站内提示，提供失败重试与最近成功时间。
- 旧快照保留且明确标记，不用失败/空响应覆盖成功历史；首次无数据给出可理解原因。
- 本版订阅指站内持续跟踪；飞书/邮件/短信外部推送与自动交易不在首版范围。

### 验收条件

1. 自行搜索关注、取消、排序、备注，刷新与服务重启后配置保留。
2. 初始营业部准确绑定；人物别名有依据与核验状态；重复关联不重复汇总。
3. 每日状态可区分无公开记录、待更新、失败、旧数据，所有订阅对象持续可见。
4. 单日/多日/不明周期正确标注，重叠披露不重复计入资金汇总。
5. 5/20/60 交易日窗口正确，趋势结论与图表、样本数量及明细一致。
6. 历史页面不展示未来行情/未来 AI 判断为当时信息；后续表现独立标注。
7. 复盘保留涨跌案例，未到期/缺失数据不填零，不显示推测的席位真实收益或仓位。
8. AI 判断有引用与反证、可保存回看，无数据时不编造分析，无未经校准的预测概率。
9. 局部来源失败保留成功历史，其余席位仍可正常阅读；既有单席位查询保持兼容。
