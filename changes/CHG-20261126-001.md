## Description

关联已发布的 [CHG-20261120-002](CHG-20261120-002.md)。同一模拟事件当天已有有效复核时，盘中报价过期、后续取数失败或部分证据缺失，页面显示「上次复核」、原判断与依据、原价和原复核及报价时间，并另行标注本轮原因。首次或下一交易日尚无有效复核显示「待核验」，新有效复核恢复更新。「已失效」保留原失效日期和核验时间。

复用策略快照 JSON 和只读契约的可选 `last_valid` 字段。业务复核读取现有基础行情和已核验日线，沿用既有有效期、调度和策略阈值，无迁移、回填、采集和模拟账本变化。

## 同轮追加 · 延续复核移入超跌反弹买入明细

用户确认按当天策略结果展示候选，正式收盘达标按实际买入日独立入账。原机会的 T+1 至 T+5 延续确认、同股同日去重及独立新确认优先继续使用线上链路。取消独立「今日复核」页签。在原买入明细显示盘中复核结论、原因及原时间，在搜索已入账股票时打开提示对应的买入记录。移植本 Change 已完成的同交易日复核保留补丁及可选 `last_valid` 契约。
