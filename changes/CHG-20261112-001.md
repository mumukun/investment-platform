# Change: CHG-20261112-001

## Title / Status

A 股当日涨跌幅与波段结算明细 / RELEASED（REL-20261112-001）

## Description

波段候选 `change_pct` 表示该行报价所属交易日的当日涨跌幅，使用与现价配对的腾讯或新浪原始百分比。盘中评估及收盘快照保存源值，持平显示 0%，源值缺失显示 `--`。历史归档保留原发布值。评估规则继续使用既有行情输入。

同轮覆盖短线、自选股、通用个股详情、盘中趋势和预警、板块个股及 AI 决策中心。其他消费契约兼容增加可空来源百分比及行情时刻。板块分组按其实际业务日匹配收盘报价。各页个股涨跌幅显示两位小数。腾讯优先，交易时段腾讯报价跨日或延迟超过十分钟时尝试新浪整笔报价；没有及时备源时保留同日延迟报价及原时间。新旧展示字段分开，策略、排名和预警阈值继续使用原有输入。

波段结算明细股票列显示所属行业，例如机械设备、通信、基础化工、医药生物。history-v4 优先使用入账证据，旧记录按本页股票及买入日关联 A 股市场快照，与原入账证据在同一条 SQL 中读取。买入时评分列展示原参与优先级或机会分，标明历史重建，缺失显示 `--`。收益和胜率沿用现有账本。
