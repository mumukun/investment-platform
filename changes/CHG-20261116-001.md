# Change: CHG-20261116-001

## Title / Status

修复超跌反弹首份收盘快照与空状态 / RELEASED

## Description

生产在 11 月 16 日开盘前没有超跌反弹快照。11 月 13 日的复权日线缺少原始收盘价，已归档的同日正式原价未被读取。补齐读取路径和缺开盘价时的核验行为。在后台首次启动时尝试使用最近已收盘交易日初始化，预先恢复受现有观察期限约束的历史收盘状态。保存实际生成时间。已有快照继续给下一交易日的真实行情提供核验依据。

看板区分等待首份快照、所选日期无数据及成功扫描后零候选。候选列表补充排序依据、修复触发价、观察低点、确认区间、成交额差距及评估日期，沿用现有选股规则与组内顺序。
