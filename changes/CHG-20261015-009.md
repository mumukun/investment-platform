# Change: CHG-20261015-009

## Title / Status

自选页面精简与信息层级重设计 / RELEASED

## Description

用户要求重新设计“自选与候选池”：筛选功能、保留添加与删除自选、整理每行布局、删除重复详情按钮、明确“移出”的含义。用户已要求直接优化，业务实现与针对性验证已完成；已按用户授权本地提交 Dashboard 代码，已通过 PR18 合并 main，main CI 与候选镜像通过。

推荐方案：

- 菜单和页面标题统一为“自选股”，默认呈现全部有效自选；取消“今日决策”和“全部自选”的重复工作区。
- 顶部保留自选数量、添加自选、刷新；用一条状态文字显示真实交易日、更新时间和异常。后台自动同步继续运行，人工同步移入更多操作。
- 默认工具栏保留名称/代码搜索、策略适配筛选（全部、短线优先、波段优先、双周期共振、暂无主策略）、市场板块筛选、排序。关注等级和研究状态不常驻，收进更多筛选。
- 列表使用对齐的股票、现价/涨跌幅、策略匹配、当前结论、关键原因、操作六列。名称为明确可键盘访问的详情入口；删除独立“详情”按钮。行业/概念作为股票辅助信息，完整分类进详情。预警保留在当前结论或关键原因中，数据异常明确显示。
- 核心目标是对每只自选同时评估短线与波段、识别当前更匹配的方向。策略匹配保留“短线结构优先、波段趋势优先、双周期共振、暂无主策略”四态；当前参与结论单独显示，不能把“波段优先”误读为“现在可以买”。列表保留两套策略的精简结论及一句理由，详细阶段、分数、入场/失效条件与证据移入已有详情抽屉。不能将页面退化成仅有行情的自选列表，也不合成跨周期总分。
- 用户明确不使用“我的用途”和“当前阶段”：列表、添加弹窗、详情展示与编辑均移除这两项，不要求用户手动指定短线/波段。暂保留底层字段和历史值，不做数据迁移或清除。实施时必须处理历史值的隐性影响：默认展示全部有效自选，不因旧“退出观察”隐藏股票；移除基于旧用途的冲突提示；页面当前结论与排序不依赖隐藏的阶段字段推断已持有，风险与预警仍对全部自选生效。研究备注按需保留。
- 候选发现从主导航收进“更多→发现候选”。核对后发现两个选股页暂无完整加入自选入口，因此保留原候选搜索与加入功能，不扩大两个选股页改造范围。
- 已移出收进“更多→已取消自选”，保留恢复能力。对外统一用“取消自选”和“重新加入”。底层仍通过现有维护命令暂停关注，保留研究历史，不物理删除。
- 取消自选用简单确认框说明“将从自选列表移除，研究历史保留，可重新加入”；取消原因不再成为必经输入。用户取消确认时不发写请求。上游成功但同步失败必须显示真实结果，沿用已有后端行为。
- 默认每页 20 只，可切换 50/100 只，避免几十只全部铺开。桌面端每条为紧凑对齐行（实测 1280px 视口标准行约 66.5px）；窄屏用三行布局保留名称代码、现价涨跌幅、策略匹配、当前结论与操作，不通过挤压六列导致横向溢出。

验收：添加按钮始终可见；搜索添加、重复提示、取消、重新加入均可用；名称可点击/键盘打开详情；没有重复详情按钮或含糊“移出”文案；取消操作不误触详情；列表可识别短线/波段适配并区别当前参与结论；用途/阶段在所有界面不再显示或填写，历史值不再隐性影响页面筛选与当前结论；现有策略与历史保留；数据缺失和过期不伪装正常。

- ADR 0014 已确认“移出”是暂停关注并保留历史。其默认行动工作台布局已由 ADR 0023 明确调整，不覆盖历史决定。
