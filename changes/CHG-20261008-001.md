# Change

## Change ID

`CHG-20261008-001`

## Title

龙虎榜席位交易与板块关注线索

## Status

`BLOCKED`

## Description

在 Dashboard 按营业部名称或代码检索龙虎榜席位（如紫阳东路），查看近期公开上榜买卖额、股票与概念/行业归属、每周和前后 30 天选股趋势报表，并按可复现的近期净买行为给出板块线索。用户可显式触发 AI，对服务端真实快照形成带交易证据、反证和观察条件的后续方向假设。席位交易不代表单一自然人、完整持仓或未来交易。不做自动交易、身份归因、收益承诺或校准概率预测。

验收：可按“紫阳东路”解析到唯一营业部代码；显示有来源与日期的交易事实、周度和前后 30 天趋势；概念缺失或上游失败时明确降级；板块线索展示计算依据与样本量；AI 仅在真实近期快照上显式调用、方向受规则线索约束并引用可查交易；浏览器不接触上游或模型密钥。

## Dependency Impact

stock-analyzer → investment-research-dashboard，新增只读契约；先部署 Provider，后部署 Consumer。东方财富公开龙虎榜 API 为外部数据源，概念映射依赖 stock-analyzer 已有分类快照。

## API Impact

新增 Bearer 保护的 `GET /api/integrations/investment-dashboard/seat-flow` 及 Dashboard `GET /api/v1/seat-flow`，参数为席位查询、观察日期及回看天数；Dashboard 新增显式 `POST /api/v1/seat-flow/analysis`。结构独立版本化，保留现有契约。

## Database Impact

Provider 使用已有分类快照表；Consumer 使用已有 Snapshot 表缓存最后成功结果及 AI 解读。无新表和迁移。

## Contract Impact

新增 `investment-dashboard-seat-flow-v1` 与 `seat-flow-rules-v2`；Provider/Consumer 分别校验版本，新增契约测试。AI 解读使用 `seat-flow-ai-v1` 提示词版本和事实指纹缓存。

## Compatibility Strategy

仅新增端点与页面，既有 API 不变。上游故障时 Dashboard 仅回退到匹配席位、观察日期的真实历史快照，并标记 stale；AI 禁止使用 stale 或过期快照。

## Feature Flag

不需要；功能上线由治理发布控制。数据不足时不生成板块线索或 AI 解读。AI 调用须用户显式触发。
