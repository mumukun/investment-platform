# Change CHG-20261116-010

## Title / Status

短线轻量同步与简版日 K · RELEASED

## Description

短线每批发布保存一份精简名单、分区保存该批次个股证据。看板同步时只取名单，通过原批次打开候选及强度实验单股详情。按原结果交易日显示最近 50 根日 K、成交额和已有确认日期，预览与行情页签复用日线。
