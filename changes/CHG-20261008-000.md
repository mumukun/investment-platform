# Change

## Change ID

`CHG-20261008-000`

## Title

Professional A-share K-line chart with paged market-data contract

## Status

`IN_PROGRESS`

## Description

Replace the shared hand-drawn daily K-line in Dashboard stock details with KLineChart, and provide a versioned, paged A-share bar contract from stock-analyzer. The chart must show real data provenance, freshness, adjustment, and historical observation semantics. Deliver daily, weekly, and monthly bars; amount, supported indicators, strategy levels, zoom and pan, and an enlarged view across the four current stock-detail surfaces.

Scope is A-share stock details already using the shared component. Minute bars, US stocks, trading, and new strategy calculations are excluded; unsupported markets remain explicit.

Acceptance: healthy current and historical bars display with correct units and dates; older bars load on demand; stale/unavailable and partial data are visibly identified; no future bars enter an observation-date view; source failure never appears as fresh data; changing symbol, period, or drawer state cancels obsolete chart work.

## Dependency Impact

`stock-analyzer` is the bar-contract provider and must be compatible before Dashboard consumes it. Dashboard continues to use its server-side Bearer client; the browser receives no upstream token and accesses no upstream database.

## API Impact

Add a versioned A-share stock-bars endpoint supporting period (`day`, `week`, `month`), adjustment, exclusive older-than cursor, bounded page size, and observation-date cutoff. Return OHLC, amount, optional genuine volume, turnover percentage, source, quality, actual trading date, generation time, last success, provisional/final bar state, and pagination metadata. Preserve the existing `investment-dashboard-swing-candles-v1` endpoints during migration.

## Database Impact

Additive storage only if needed for genuine daily volume or provenance/freshness metadata. Existing `swing_daily_bar` and strategy snapshots remain valid; do not backfill or overwrite production data as part of ordinary tests.

## Contract Impact

New `investment-dashboard-stock-bars-v2` structure; no strategy `rules_version` change. Provider model, Dashboard adapter, frontend types, fixtures, and contract documentation change together. `investment-dashboard-swing-candles-v1` keeps its semantics during the compatibility window.

## Compatibility Strategy

Add new endpoint and keep the old one. Deploy/provider-verify first, then consumer. Old Dashboard remains operable until rollout finishes. Reject unknown versions and malformed bar data explicitly.

## Feature Flag

Required for switching the shared K-line to the new provider-backed chart. Default off until contract and UI validation; disabling returns to the existing chart without changing strategy decisions.
