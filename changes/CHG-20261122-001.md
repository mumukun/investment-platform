# Change CHG-20261122-001

## Title / Status

移除 Dashboard 的 AI 决策中心。RELEASED，生产已切换。

## Description

- 桌面和移动共用的菜单移除入口，旧书签 `/decisions` 重定向到全球投资看板。移除页面、每分钟轮询、专用详情展示和模拟入口。
- 盘前摘要保留隔夜市场和事件日历，两张决策卡片及查询退出。四个原决策 HTTP 接口退出路由，已有决策、反馈、审计及复盘数据留存在原表。
- 移除专属交易日历同步协程、快照写入及任务目录条目。短线、波段、自选、共享行情和历史复盘继续原有职责。

## Release Impact and Rollback

仅 Dashboard 需要交付。原日历同步在配置上游且非演示模式时启动，每轮结束后等待 900 秒；新版本取消此任务。生产 CPU、内存和数据库 I/O 实际差值未测量。stock-analyzer、marketNewsFeed 均无修改。

删除 Dashboard 自身既有 API 属于不兼容变更，本地版本 2.23.0 → 3.0.0。旧网页书签自动转向首页，直接使用旧 API 的客户端需移除对应调用。无新数据库迁移。若后续发布需要回滚，使用届时核实的上一个 Dashboard 生产制品；旧表与历史记录可继续使用。
