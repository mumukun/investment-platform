# Change

## Change ID

`CHG-20260926-003`

## Title

Restore Daily Market and Capital-flow Projection

## Status

`RELEASED`

## Description

Production market dashboard and capital-flow history stop advancing unless a user opens the corresponding
data page during the trading day. Add a Dashboard-owned background projection that archives the real
`short-selection` and `capital-flow` contracts during the A-share day, without changing Provider rules or
contracts.

Acceptance criteria:

- market dashboard inputs no longer depend on browser traffic;
- one real, idempotently updated snapshot per available trading day is retained for both domains;
- intraday refresh and a post-close refresh preserve current and final data;
- one upstream path failing does not discard the other path's successful snapshot;
- weekends do not continuously call the current-day capital-flow API;
- existing page-triggered refresh, historical reads, last-known-good fallback and readiness behavior remain;
- no Production deployment, Tag, release or database backfill is performed in this Change.

Non-goals: reconstructing capital-flow days already missed by the current-day-only Provider, changing
`stock-analyzer` calculation rules or contract payloads, and releasing to Production.

## Dependency Impact

Existing `stock-analyzer → investment-research-dashboard` read-only APIs are reused. No dependency edge,
minimum compatible contract or release order changes. If released later, only Dashboard needs a PATCH release.

## API Impact

No endpoint or payload change. Existing `GET /api/v1/capital-flow`, `GET /api/v1/short-selection` and
`GET /api/v1/dashboard/{session}` behavior is preserved while the first two share the background projection's
idempotent persistence implementation.

## Database Impact

No schema or migration. Existing `snapshots` rows are upserted by domain and trading date, and a distinct
`sync_states` row records background projection health. Historical gaps cannot be safely backfilled because the
capital-flow Provider exposes current-day minute data only.

## Contract Impact

None. `investment-dashboard-capital-flow-v1` and
`investment-dashboard-short-selection-engine-v1` remain unchanged and continue to be validated by the existing
Consumer client.

## Compatibility Strategy

Backward compatible. Browser-triggered refresh and last-known-good fallback remain available. Setting
`MARKET_PROJECTION_SYNC_SECONDS=0` disables the new background task.

## Feature Flag

Not required. The safe operational disable path is `MARKET_PROJECTION_SYNC_SECONDS=0`; default is 300 seconds.
