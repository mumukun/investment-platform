# Change: CHG-20261120-002

## Title / Status

超跌反弹五日延续机会与今日复核 / RELEASED（REL-20261120-001）

## Description

用户在某轮信号首次被模拟买入时可能尚未实际决定参与，需要继续查看同一轮机会在 T+1 至 T+5 的参与条件。用现有盘中筛选计算独立复核，显示状态、现价、原区间、风险和最近 20 个已收盘交易日均额。基准核验失败显示待核验，可靠报价跌破失效位后持续提示失效。

候选搜索提示同股已有模拟记录，并可进入今日复核或模拟跟踪。旧禁止追高记录标记为历史。新独立异常下跌可以进入正常候选，上一笔的成本及五日收益继续按原事件记录。今日复核列表每页 100 条，与 CHG-20261120-001 的候选主列表一致。
