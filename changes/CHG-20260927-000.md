# Change

## Change ID

`CHG-20260927-000`

## Title

恢复生产波段候选并激活涨停梯队

## Status

`RELEASED`

## Description

修复 `REL-20260926-001` 发布后的两个生产可用性问题：`stock-analyzer` 已切换到
`swing-rules-v5.1.0`，但发布门禁没有先生成最近交易日的同版本收盘快照，导致 Dashboard 报
`swing_setup_snapshot` 无数据；涨停梯队代码虽已部署，但 Dashboard 前后端 Feature Flag 仍为关闭，
因此用户看不到入口和数据。

本 Hotfix 仅做恢复性处理：对 2026-09-25 先 dry-run、再执行一次幂等 v5.1 收盘扫描；将 Dashboard
以 PATCH 版本发布，并在生产配置中同时启用 `LIMIT_UP_LADDER_ENABLED` 与
`VITE_LIMIT_UP_LADDER_ENABLED`；将 `STOCK_ANALYZER_TIMEOUT_SECONDS` 从 20 提高到 60，覆盖完整候选响应
在生产实测接近 20 秒的情况。不上调规则版本，不改契约与业务算法。

验收标准：生产波段 V3 契约返回 `ok=true`、规则版本 v5.1、最近交易日及非空候选；Dashboard 波段接口
不再出现无快照或偶发上游超时；涨停梯队前端路由和后端代理均启用，返回五个真实交易日数据并明确保留
`partial` 数据质量状态。

为 `false` 并回滚 Dashboard 到 `v0.14.0`。本次按用户明确要求覆盖原“等待原生快照再激活”的门禁，
接受当前五日真实但 `partial` 的上游质量标识。
