# Change: CHG-20261103-001

## Title / Status

个股盘中 K 线与短线候选确认分类 — RELEASED，REL-20261103-001。

## Result and scope

修复上午打开个股专业 K 线仍截止昨日的问题：当前查询（含显式今天）只读基础层已发布报价，内存组合当天未收盘日/周/月蜡烛，并显示真实报价时间。缺失、无效或非当天报价不伪造今日数据；历史日期与向前分页不混入未来报价。结算/模拟/短线/自选候选入口按页面观察截止日查看，买入/证据日期独立保留。

短线候选清单沿用既有页签，新增“当日确认 / 此前延续”，仅分类当前“可计划参与”的股票。Provider保存最早已核实参与确认日期，在同规则、同股票、同结构路径有效时跨日保留；每天仍独立通过原五分钟确认，失效/换路径重新确认。历史缺依据不猜日期，未知日期只留总清单。Consumer验证确认日期与时间，手机页签在清单内部滚动。

没有更改选股门槛、评分、收益账本、行情来源、采集计划、数据库结构或Feature Flag。没有新增依赖、来源请求或基础行情写入。short-research-v1兼容追加可空confirmation_trade_date / confirmed_at；沿用stock-bars-v2等现有结构语义。marketNewsFeed排除。
