# Change: CHG-20261021-006

## Title / RELEASED

修正行业资金分钟曲线可读性 / REVIEW（本地未提交）

## Description

用户反馈资金曲线不如旧版本平滑，并提供时间标签严重叠加、曲线碎裂的截图。当前生产基线5961d61已包含CHG-20261020-001的smooth=0.25，并非平滑代码未上线。旧链路按5个分钟点抽样，当前Sina observed-snapshots逐分钟保留事实与null；xAxis仍写死interval=1，相当于每两个点显示一个标签。孤立点即使已有短缺口连线仍重复打点，进一步造成碎裂观感。

改为按像素宽度选择半小时/首尾时间刻度、隐藏重叠标签，resize时重算；连续线smooth=0.4与圆角；已有短缺口连线的点不再重复打圆点，真正孤立事实点仍可见。不改金额、时间轴、null、短缺口/长缺口规则、数据源和tooltip，不用均值或删点掩盖采样跳变。
