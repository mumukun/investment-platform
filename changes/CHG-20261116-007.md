# Change: CHG-20261116-007

## Title / Status

盘中性能采样与慢查询诊断 · RELEASED

## Description

复用交易日历、行情批次、策略轮次、看板响应就绪日志和 PostgreSQL 统计。交易时段只读采集每分钟基线，可在上午和下午分别开启每 10 秒一次的限时活动查询采样。Markdown 报告列出短线、波段和超跌反弹的慢响应、选股轮次、长查询和等待事件。临时写入增量、页面请求和活动查询按时间对照，缺乏共同标识时保持归因未确认。采样不主动请求选股接口、不读取 SQL 文本。超跌反弹记录私有全市场扫描耗时。

## Evidence and Remaining Work

2026-11-16 18:32–18:34 北京时间，临时只读运行采样器读取生产数据。波段和短线均触发原有 2 秒探测超时；超跌反弹返回 HTTP 200、544.2 ms。延长一次复测等待后，波段返回 HTTP 200、4291.2 ms，响应 155107713 字节；短线返回 HTTP 200、1158.9 ms，响应 8462145 字节。均为生产 stock-api 回环请求，非看板浏览器实测。短线采样前一分钟股票库新增 13361152 字节临时写入，并观测到一条 DataFileRead 等待，不能归因到具体接口或 SQL。

上述测量使用此前的主动探测方式。本地实现现已改为读取看板日志，生产未部署新脚本或修改数据。

待实际交易时段采集生产证据，验证覆盖、采样负载及错峰效果。具体 SQL 优化依据生产定位结果处理。
