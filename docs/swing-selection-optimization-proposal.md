# 波段选股整体优化方案：发现、跟踪、确认与风险

Change：CHG-20261022-004。2026-10-22，待用户评审。

本方案替代此前仅覆盖MA20的草案。用户要求先讨论完整方案，再开发；当前没有业务实现、效果回测或发布。

## 1. 目标与推荐方向

服务5～20日波段研究：整理阶段提前发现，承接阶段制定参与计划，走强或加速阶段评估兑现风险。成功不以是否吃到后续连续大涨衡量，也不把启动后的表现倒灌为启动前选股依据。

保留低位蓄势、趋势通道、突破回踩三条独立路径，形成“数据与资格→发现→持续跟踪→入口确认→风险→排序与解释”的统一流程。价格用波动区间，量能与斜率区分明确/临界/不满足，状态依赖连续证据，数据与风险保留明确否决。

最小替代方案是只补原因解释，但不能解决观察池遗漏和确认语义耦合。本方案同时处理发现与确认。另一替代是改成机器学习或综合机会分；本轮不选择，因为增加样本、校准与解释成本，也容易用其他高分掩盖关键风险。继续复用确定性规则、现有行情、进程和数据库。

核心假设：部分现有拒绝来自噪声、重复条件或入口耦合，而非真实结构恶化。若新增样本主要是下跌中继，假设不成立，必须保留原参与算法，不能继续扩大误差获取更多股票。

以下新数值全部是预先登记的研究候选，不是已验证最优值。冰山冷热只作解释回归案例，不决定参数，也不进入最终效果检验。

## 3. 产品语义：不增加第五个参与决策

继续保留暂缓参与、可计划参与、禁止追高、不参与。生命周期回答形态发展到哪里；确认方式回答如何通过；参与决策回答是否达到参与要求。

新增“重点观察”是视图/关注层级，不是试仓、买入或参与状态。方法区分严格确认与边界承接确认，不展示未经验证的胜率。

| 列表表现 | 含义 |
| --- | --- |
| 可计划参与·严格确认 | 入口条件严格满足 |
| 可计划参与·边界承接确认 | 仅一个证据组处于允许边界，其他组严格满足，额外持续确认完成 |
| 重点观察·暂缓参与 | 结构成熟且接近下一条件，尚缺确认或参与流动性 |
| 普通观察·暂缓参与 | 结构仍在形成，显示下一条件与实际等待时间 |
| 禁止追高/不参与 | 加速、风险或结构失效，含义保持 |

重点观察要求：当前数据健康；风险可评估且在现有预算内；处于蓄势增强、接近启动、平台前蓄力、趋势回踩中或回踩待确认之一；距离对应关键区域不超过现有1.5ATR近位口径；没有结构破坏或市场/行业退潮；最多一个证据组处于边界，或者只差参与流动性/入口的下一次确认事件。

参与流动性不足者明确显示“仅观察”，不能伪装成马上可以买。陈旧、未知交易资格和缺必要事实者不进入重点观察。重点观察依次按结构成熟度、尚缺条件数量、关键区域距离、最近结构事件时间、风险距离排序，以代码稳定打破并列；不新增综合机会分，不强制凑数量。

可计划参与仍使用现有35/25/20/15/5参与优先级权重。临界通过不自动获得严格条件满分，不因新标签加分。三路径独立评价，一股仍一行，不能混合证据抵消另一条路径的失败。

## 4. 发现资格与观察留存

### 4.1 分离流动性门槛

候选：新发现观察门槛为20日平均成交额至少5000万元；正式参与维持至少1亿元。4000万/6000万只作观察范围的邻近敏感性检查，不在最终留出集选择最优值。60日量能等既有指标用于解释稳定性，不额外叠加必须通过的门槛。

真实交易日、证券规则、上市历史、至少120根有效同口径日线及缺失/陈旧隔离保持。data_health与runtime必须统一为新的观察范围，不能仍先用1亿元做数据验收，再声称扫描了更低流动性股票。

已入池股票缩量跌破观察门槛时，保留为延续观察并标流动性不足，不产生新参与确认。结构失效、交易资格变化或到期结束该事件。停牌、一字板等不可参与事实始终显式显示；保留历史跟踪不等于继续声称可交易。

### 4.2 观察事件有开始与结束

每股票、每路径由首次合格结构建立事件，沿用20个真实交易日观察周期。记录首次发现、最后有效结构日、最近阶段变化、确认日期和结束原因。报价刷新、页面访问或价格微动不重置周期。

到期/失效后同日不复活；下一真实交易日重新满足结构条件时建立新事件，旧事件保留。已确认样本继续原账本跟踪，观察到期不撤销亏损或待结算。低位股票成功走强后超过原低位线，按既有路径连续性演化，不重新冒充新增低位机会。

## 5. 关键边界分类：完整覆盖，但不统一放宽

### 5.1 每类条件采用不同方法

| 类型 | 处理方式 | 首轮候选定义 |
| --- | --- | --- |
| MA5/10/20支撑或转强的价格比较 | 波动区间 | 容差金额取0.20ATR20与参考均线0.50%的较小值；仅用于支撑/转强入口 |
| 真实突破、冻结枢轴重新收复、VWAP转强 | 真实事件条件 | 保留明确站上要求，不把尚未突破当成容差突破 |
| MA20接近零的斜率 | 上行/走平/下行分区 | 原5点回归斜率换算为ATR/日；零区宽度取0.02ATR/日与均线0.03%/日的较小值 |
| MA60与成熟度 | 辅助/成熟信号 | 保持原角色，不新设一票否决；新生趋势仍可在MA60修复中被发现 |
| 低位位置 | 进入与延续分开 | 35%以内正常新增；35%～40%可新增边界观察，未曾进入正常低位事件者须回到35%以内才能按低位路径确认；已有走强事件按状态延续 |
| 近期低点 | ATR识别轻微下探 | 低位原零边界增加下探不超过0.20ATR的边界观察；通道已有-0.50ATR、回踩已有-0.30ATR不再扩大 |
| 承接额比上限 | 明确/临界/过量 | 该入口原上限以内严格满足，超过但不超过原上限1.10倍为边界，再高不满足 |
| 收盘位置 | 强/中性/弱 | 承接原55%以上严格满足；50%～55%为边界；低于50%不允许边界确认；原45%弱收盘限制保留 |
| 枢轴附近、短期波动压缩 | 保留现有合理区间 | 已有ATR区域不叠第二层容差；压缩、回踩、突破使用各自阶段含义 |
| 市场/行业、风险、数据 | 明确资格与否决 | 退潮不新增参与；失效位、2.5ATR风险预算、加速和不可交易不允许其他证据抵消 |

额比边界只适用于承接入口的日额比/同时段额比，不能扩散到所有量能指标。原突破量能上下限不放宽；长期沉淀的多个辅助额比仍沿用至少两项满足的组合，不额外要求全部完美。

原观察阶段明确下行限制保留；走平分区主要处理正式承接的零斜率边界。低位走平可以进入边界确认；趋势通道的走平只有已有成熟趋势及回踩前序时才可能使用，不能把横盘股票直接称为趋势转强。缺失与明确下行不能混为走平。

### 5.2 四个证据组与补充确认

必要条件归入价格位置、方向与低点结构、量能、收盘/周期强度四组。MA5和MA20归同一价格组，多个量能比归同一量能组，不重复计票。数据、证券资格、参与流动性、市场/行业和风险单独否决。

组内状态取必要条件中最差的一项；不平均、不用多数好条件抹去明确失败。观察位置、辅助成熟指标与正式参与必要条件的角色逐项登记，不能把原辅助条件悄悄升级成新的否决条件。

边界确认必须：必要资格全通过；四组没有明确失败；至多一个组使用边界；其余组严格满足；当前收盘/完成周期价格不低于上一收盘/完成周期；没有跌破冻结失效位。轻微低点下探只有收盘保持在前3个完整交易日最低收盘之上且原失效位未破，才可被视为结构组的边界；低点下探本身不构成参与依据。

盘后边界确认需要两个连续真实交易日分别通过同一入口、同一边界组的规则，第二日确认；每天都使用当时可用输入，不要求数值相同。期间其他组转弱、量能过热、失效或数据缺失即重置连续计数。严格确认沿用原跨阶段要求，不无故增加一天延迟。

盘中边界确认需两个不同的连续完整5分钟周期满足对应入口，保留VWAP与同时段量能历史要求；同一根bar被轮询两次不能计为两个周期。缺周期、缺历史、当日失效不能靠容差补足。收盘重新判断，盘中不直接产生收盘买入。

多组同时临界仍为暂缓参与：不能用均线弱一点、结构弱一点、量能再弱一点共同拼出一次确认。该规则只区分证据强弱，不是新的加权综合分。

### 5.3 精度与引用时间

在同一复权/价格尺度上先计算和判定，再做显示四舍五入；0是有效数值，不能用真假值表达式把零斜率或零低点变化当缺失。小于一个报价单位的容差不强行放大成一格报价。

盘中发现仍可使用标记明确的盘中特征；支撑确认的均线、ATR和平台边界使用最近完整交易日基准，按既有报价复权尺度对齐后日内固定，价格、VWAP、成交额及完成周期更新。盘后使用当天完整日线，解释结果可能不同。突破锚点冻结后不被滚动窗口覆盖，不用未来数据扩张容差。

## 6. 三条路径分别优化

| 路径 | 提前发现什么 | 正式参与入口 | 主要改变 |
| --- | --- | --- | --- |
| 低位蓄势 | 低位止跌、波动/成交额沉淀、低点改善 | 平台内承接；或原有启动站稳/启动回踩 | 平台内承接不隐含要求先站上平台高点；允许受约束的边界承接 |
| 趋势通道 | 均线与低点结构具有持续性 | 回踩后重新转强；高位回撤后二次转强 | 用MA10/20支撑区域观察，MA5/10转强按价格边界处理，MA60只承担成熟度角色 |
| 突破回踩 | 压缩且接近压力位的平台 | 真实突破→冻结平台→回踩→重新收复 | 保留事件顺序，已有回踩范围不额外加宽，不跳过首次回踩 |

周期确认按入口计数：低位看支撑承接与VWAP，趋势看回踩后的短期位转强与VWAP，突破回踩看冻结枢轴重新收复。不能再用通用“站上key_level两根bar”覆盖全部入口，也不通过降低周期数量修补语义。

量能随阶段解释：蓄势看沉淀，承接看正常/收敛换手，突破看真实放量，回踩看量能回落。不新增OBV一票否决，不要求所有辅助指标同时完美。

市场环境本轮不大幅调参；实际门禁与页面说明必须一致，缺失不能假装健康。核查前一交易日环境、行业离散度等必要输入的传递，不以沿用旧模型的文案代替真实决策。退潮保留观察、停止新增参与，不以热点题材越过限制。

## 7. 风险、加速与兑现关注

正式确认时冻结入场参考、结构失效位、初始R、所用均线/ATR/枢轴和方法。之后失效位只能按已登记规则收紧，不能随回撤下移扩大原始风险。首次突破时冻结平台及对应失效条件，不随滚动高点替换锚点。

保留有效失效位、最大2.5ATR风险距离、既有加速与不可交易限制。价格容忍不豁免实际结构破坏，其他组严格满足也不能抵消硬风险。

对跟踪对象展示距箱体上沿、原始R、加速与结构转弱事件，供用户评估兑现；对新进入者仍显示追高限制。平台不知道真实持仓，不自动标“你应卖出”、不生成仓位建议或下单；不新增未经验证的最优卖点模型。

固定5/10日研究和结构事件研究分开：中途触及失效位或加速，原样本仍保留结算，不删除失败样本或事后挑最有利卖价。

## 8. 固定验证协议与采用门槛

### 8.1 逐组比较，记录全部试验

冻结原V5.2.0基线，整体候选使用独立V6。固定参数后比较：仅发现/跟踪变化；仅价格边界；仅方向/低点边界；仅量能/收盘边界；仅入口/周期语义修正；完整候选。每组只改相应因素，不能在留出集中挑一组历史最好就宣布整体有效。

邻近检查只在完整候选中逐项改变一个参数，不做全组合搜索。冰山冷热及其他已经看过/用于调参的样本单列开发或案例区，不能称为未见数据。统计显著性检查保留全部试验次数，不只记录获胜版本。

用同期证券范围、真实交易日、同口径复权和交易规则重放，包含失败整理、停牌、退市与不可交易。不能重建的部分隔离并披露选择偏差。仅用获准腾讯/新浪和项目历史事实，不补造缺失或自行引入数据商。

### 8.2 时间与样本

按时间划分50%开发、25%滚动验证、25%最终留出，先固定边界再比较。按最长10日辅助窗口清除区间边界重叠标签，禁止随机拆分股票日。滚动区分成3个连续时段报告，不只给总平均。

每条改变参与条件的路径，最终留出至少60个真实交易日、新增/提前组至少200个已结算去重可交易样本，才进入效果评审。200是最低数量，不保证显著性；还要考虑同日、同行业相关性。历史不足标待验证，不自动缩短要求，不强制新增生产观察期。

### 8.3 完整评价旧新差异

分开报告共同确认、旧规则独有、新规则新增、同股提前/延后四类。检查新规则排除的旧信号，不能靠删掉亏损股票美化效果。同股按原窗口去重，提前入场替代后来信号的影响单列。

观察层：首次发现提前量、缩量消失次数、观察留存、重点观察日均数量、无效等待。参与层：5日主结果、10日辅助结果、MFE/MAE、先-1R或+2R、确认提前天数、失败率、板块/市况分层。加速不是自动买点，后来大涨不是唯一成功定义。

保留产品原有收盘理论入场统计；采用判断另用下一真实交易日开盘可执行口径，停牌、一字板、开盘已越过失效位单列不可交易。往返摩擦30bp为主、50bp为压力假设，不冒充用户实际费用或成交。

### 8.4 采用约束

数据、功能和样本要求均满足；每条改变参与条件的路径，新增加/提前组在下一日开盘口径扣30bp后的5日平均收益95%区间下界为正；以R计的95分位MAE和先-1R比例不高于同期按板块/市况分层的原路径组。多路径检验使用Holm方法控制5%错误率；用5交易日时间块重采样，另报告10日块敏感性，不把同日股票当独立样本。

完整披露50bp压力、邻近参数、旧规则独有组与三个滚动区间。风险恶化、只在个别时期有效或历史不足，不自动扩大容差或用其他路径利润抵消，参与采用结论回到用户评审。解释/观察改进可独立交付，不代替参与规则的效果验证。
