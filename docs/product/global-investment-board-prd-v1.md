# 全球投资看板 PRD v1.0

日期：2026-10-15。Change：CHG-20261015-002。用户已授权开发首版并在验证完成后正式上线。

## 目标与边界

替换“市场驾驶舱”首页，展示A股、港股、美股、股指期货、贵金属、能源、汇率与官方重点事件，回答“全球市场现在是什么状态”。只呈现第三方事实与可解释的价格变化，不输出跨资产买卖评分。原型参照用户提供的三张卡片式看板截图。

首版不新增服务。行情所有者为stock-analyzer，Dashboard通过Bearer版本化契约保存本地投影，浏览器不访问第三方或上游数据库。News不变；短线、波段、资金流、市场结构与ETF、美股隔夜映射保持独立。下线市场驾驶舱导航和页面请求，旧/dashboard跳转/global-board，旧兼容API保留供既有消费者使用。就绪检查兼容旧market-dashboard配置名：新全球投影存在后改检查其时效，不再依赖旧驾驶舱的短线/资金流双快照；首次新投影前保留既有检查。

## 页面与交互

首页标题“全球投资看板”，默认常用指数、贵金属与能源、金融期货、外汇、自选关注五组。核心品种可收藏、隐藏、调整显示顺序；设置仅保存在当前浏览器，不承诺跨设备同步。自选关注读取既有自选池的活跃证券，最多20只，不导入持仓或成本。

卡片展示名称、类型、来源代码、价格、报价单位、涨跌额/幅、真实行情时间、来源与质量状态。指数使用千分位而不缩成“万”；涨红跌绿，符号始终保留。贵金属明确美元/盎司与人民币/克；期货与现货分开，VIX期货不标为VIX现货指数。

卡片统一展示“当日分时·报价采样”，仅使用当日已保存的有效报价，不再自动回退历史日K；少于两个有效点时提示采样不足。卡片标明日期口径：美股按纽约当地日期（含夏令时），其他品种按北京时间自然日；夜盘按此自然日分段，不冒充交易所业务日。详情默认当日分时，可切换“原始日K”，历史OHLC仍完整保留。卡片与详情共用当日采样范围（上游最多最近600点），不再仅取卡片最近120点；仍不承诺完整当日分时。

采样从上线开始积累，禁止造历史、从单价补OHLC、把成交量当成交额、跨日期/长断档连线。历史OHLC用第三方发布值；缺失显示原因。新浪外盘已发现部分日期OHLC上下界无效，剔除这些原始记录并显式列出历史缺口，不修正高低价来造完整序列。连续期货标明连续品种，未经核验不混接其他来源的换月序列。此展示调整经用户于2026-10-15确认，见CHG-20261015-003。

日历显示今日/未来7天/未来30天、事件名、北京时间、来源、确认状态、规则重要分类和最后核验时间。首版为美国官方重点事件日程（已验证Fed、BEA；BLS公开日程在当前访问环境返回403，CPI/就业日程未接入），不是完整全球经济数据终端。默认未来30天，避免稀疏官方发布日程造成首页误判为空。官方来源不提供的市场预期/前值/公布值不补造。综合日历与其他国家扩展不阻塞行情上线。

央行政策利率、国债收益率：首版不显示未验收模块。后续使用具名官方数据而非报价近似值；收益率变化使用bp，政策利率说明具体工具。日经/富时现货、VIX现货暂不纳入默认目录，新浪旧int_*接口无时间戳且值明显不同，不合格；不能以日经期货替代日经现货。

## 来源与目录

常用中国指数：上证、深成指、沪深300、创业板、科创50；香港：恒生、恒生科技；美国：道琼斯、纳斯达克综合、标普500。腾讯报价优先，失败、缺标的、代码身份不一致、时间无效或交易时段显著陈旧才转新浪；备用同样校验。美股新浪用带时间戳gb_*，不使用旧int_*接口。

新浪专用品种：COMEX黄金GC、白银SI、WTI CL、布伦特OIL、天然气NG、伦敦金XAU；A50 CHA50CFD（来源连续参考报价，非已验证指定交割月）、道指YM、纳指NQ、日经NK、VIX期货VX；国内沪深300 IF0、黄金AU0；美元指数DINIW、离岸人民币fx_susdcnh。各代码为来源映射，不当作全平台统一代码。报价批量直连，超时有限，无固定IP、无全局代理修改。

腾讯指数历史日K与新浪外盘历史日K逐项校验OHLC、日期和类型后入库；历史回填只写本模块新表，不改旧历史。股票首版仅展示未复权价格，不与策略复权序列混用。

## 更新、数据模型与降级

Provider单独后台循环：正常工作日每60秒批量采集；周末降到15分钟，当前仍需获取收盘记录与日历变化。报价缓存按原始data_time去重，静止收盘行情不会每分钟造点。历史日K/官方日历启动及每日更新，失败延后重试，不把所有失败写成空历史。

行情事实表包含instrument_id、kind(quote/bar/calendar)、source、data_time、collected_at与JSONB原始规范事实，复合主键幂等。采集运行表/记录保存成功与失败来源、覆盖与更新时间。旧事实不删除；首版记录增长，后续根据实际量制定采样保留策略。

契约：investment-dashboard-global-board-v1。对象级数据时间/时区、来源、质量、OHLC/单位、基准类型、采样与历史必须明确。交易时段采用周时段参考，不假称已具备全部节假日/交易所日历；外盘来源延迟未知明确标记。美股纽约时区处理夏令时，国内夜盘业务日与报价时刻分开。

Dashboard后台60秒同步Provider已存储数据，浏览器30秒读取本地投影。失败保留最近有效投影并展示最后成功时间；一项失败不清空其他卡片，日历失败不阻断行情。收藏隐藏不产生额外外部请求。生产不回退演示数据。

## 验收与发布

验证：腾讯/Sina正常、空值/错码/缺时间、非有限值/未来时刻、陈旧降级、批量部分失败、纽约夏令时、国内夜盘、日K日期/OHLC、采样断档；Provider→Consumer契约、失败保留投影、页面排序收藏/隐藏、移动端布局与认证。新增Provider表在隔离PostgreSQL验证初始化/幂等；Dashboard复用Snapshot/SyncState，无新migration。

受影响仓库stock-analyzer与investment-research-dashboard各升MINOR，先Provider后Dashboard，版本与测试随业务PR，main CI生成精确候选镜像。按治理流程一次部署、备份、健康与受影响只读链路核验；保留当前稳定生产镜像与旧/dashboard重定向回退能力。治理归档包括实际遗留与未覆盖来源，不能把mock测试记为真实源通过。
