# 科技看板产品需求文档

版本：1.0。日期：2026-10-15。Change：CHG-20261015-005。状态：首版本地实现与验证已完成，按用户授权本地提交，待验收；未推送或发布。提交SHA见Change记录。

## 目标与已确认决策

新增独立“科技看板”，聚焦 AI 硬件与算力产业链。用第三方板块或指数行情回答“已接入范围内，今天哪些方向表现靠前”，并能查看对应成分股、关注个股、保存收盘记录、回看历史。

用户已明确：**只使用第三方板块或指数，缺少数据就不排名。**不启用此前讨论的观察池平均、中位数、上涨比例、合计成交额或自定义强度分。前期候选公司清单不是正式成员名单。

数据源预算约束：**零新增数据订阅费，不使用 Tushare，不购买积分、付费接口或付费采集服务。**后续补齐细分领域也遵循这一约束，不将付费账号列为开发前置条件。

本次核查支持四条具名国证指数的最小数据范围，尚不支持所有科技细分领域都有完整免费盘中榜单。具体范围见 [数据源核查](tech-board-data-source-audit-2026-10-15.md)。页面必须如实展示范围，不将这四条指数包装成完整 AI 硬件行业覆盖。

## 产品闭环

1. **发现**：打开页面，看当前有效指数的涨跌幅排序和最多三条事实摘要。
2. **核验**：点击指数，看发布方、代码、成员日期、完整名单与个股行情。
3. **关注**：将证券或指数加入个人关注，打开既有个股详情或关联研究记录。
4. **留档**：保存当天第三方原始行情、成员版本、榜单范围和摘要。
5. **对照**：回看某日快照，与其他日期对照；不能用现在的成员反算过去。

首版使用已核查的公开免费来源，提供发现到回看的完整路径；新闻功能不构成使用前提。

## 页面结构与视觉

沿用应用整体风格，用宽幅布局、留白、细分割线组织内容。界面品牌色保持紫色；行情正负按既有全局设置及明确的正负号呈现，不把品牌色解释为涨跌。

```text
科技看板   AI硬件与算力产业链     A股 / 港股参照 / 美股参照
交易日 · 盘中/盘后状态 · 行情时间 · 本次可比较范围 · 数据状态

今日速览：当前较靠前指数 / 当前较靠后指数 / 数据缺口提示

左：产业链目录       中：有效指数横向条形图与原始涨跌幅榜
                    右或下：选中指数的完整成分与个股走势

我的关注            历史日期选择 · 收盘快照 · 研究记录入口
```

未接入的细分领域在可展开的“待接入目录”中保留，不堆成满屏空行情卡片。不用人工候选公司填充正式成员表。筛选只影响可见成员，不改第三方指数涨幅；筛选后明确提示“当前仅显示部分成员”。

### 今日速览与排名

- 默认按第三方发布的当日涨跌幅排序，按“发布方/分类体系 + 市场 + 业务日期 + 盘中或收盘”限定比较集合。
- 图表使用原始百分比；比例到百分数、元到亿元等仅做单位转换。不得自行推导涨幅或计算组合收益。
- 排名只描述已接入集合。标题使用“已接入国证指数表现”，不写“全市场科技板块排行榜”。
- 数量不足三条就展示实际条数；全部为负时称“跌幅较小/较大”，不称“上涨最强”。只有一条时不生成比较结论。
- 列表通用字段为原名、发布方代码、指数点位、原始涨跌幅、源时间和状态。成交额、家数等字段仅在来源定义、单位与日期均通过验收后展示；首版不加总成分数据补字段。
- CPO等同花顺专题不混进国证指数榜。后续接入不同体系时使用独立切换项。

### 总结规则

采用确定性模板，不增加 LLM 调用。每条句子引用同一快照中的第三方值、排序范围和数据时间，点击后可核对来源。

允许：在已接入的具名指数中描述涨跌幅大小、列出原始报价、说明缺失与陈旧来源、链接个人关注。

不允许：从个股计算上涨比例或扩散指标；推断资金流入、产业链传导、上涨原因、趋势持续概率；生成买卖建议。第三方若未提供合格字段，摘要不生成相关句子。没有足够当前数据时显示“当前不足以比较”，旧摘要只在其原始日期下显示。

### 成分与个股

完整成员取相应第三方名单，显示成员数据日期及最后核验时间。用户可以按第三方个股涨跌幅、名称排序；“涨幅靠前”不等于行业龙头。

优先使用可靠原始分时，缺少分时但有报价采样时明确标记。日 K 在详情展示；缺口不连线，不把单价补成 OHLC，不跨来源拼接不兼容的复权序列。

截图 8 只证券可进入“用户指定关注”，来源为用户选择：688498、688808、300308、HK01879、300502、300757、688167、688048。此名单不产生板块指标、不强制归入 CPO，也不覆盖发布方的真实成员。

首版个人关注使用本地浏览器偏好，与现有全球看板一致，不承诺跨设备同步。A股/美股的既有自选维护能力仅在契约支持时复用；不向不支持港股的旧接口强行写入HK01879。已有研究记录通过证券身份关联，不能把未实现的港股详情宣称已复用成功。

## 收盘归档与历史回看

收盘快照保存指数原始字段、源时间、成员版本引用、比较集合、显示排序、摘要与来源证据引用。排序序号属于展示操作，不产生新的板块收益指标。

- 15:00 后先标为“盘后待核验”；当来源发布对应日线后补充原始日 K，晚到数据保留修订记录。
- 未取得今日收盘记录就明确显示上次有效日期，不用“同步成功”掩盖业务日期落后。
- 原始历史日线可用于走势图；历史排名仅使用第三方历史原始涨跌幅或上线后存档值，不从历史收盘价自行生成。
- 历史成员仅使用当时已保存或第三方明确发布的版本。首次采集之前不承诺恢复历史成员、历史摘要或当时的关注状态。
- 最近五个交易日比较在有足够可比快照后出现；发布方、证券身份或分类体系变化时分段，不能拼成一条连续比较。

## 更新与降级

首版实现为：北京时间工作日09:20—15:20共享行情采集循环约60秒更新，其他时段约15分钟；Dashboard后台60秒同步，浏览器30秒读本地缓存。此能力尚未部署生产。报价采样根据源时间去重，打开多个页面不增加第三方请求。成员每日核验一次并接受完整快照，失败保留上次版本。

日线在启动及15:20、17:10、20:30所在轮询窗口核验一次，不保证准确秒点执行；未齐全则次日重试，不无限轮询。实际更新速度取决于上游，网页请求频率不等于行情实时性。

交易日、行情源时间、成员日期、日线日期、采集时间分别保存。盘前与休市显示最近已核验交易日；各市场按自己的交易日与时区处理。首版不能声称已覆盖全部交易所节假日，缺少可靠日历时用明确的“时段参考”状态并以来源交易日期为准，不为判断休市调用东方财富日历。

| 异常 | 产品行为 |
| --- | --- |
| 名称/代码不匹配、原始涨跌幅缺失、源日期或时间无法核验 | 不参与当前榜，显示原因 |
| 个股部分缺失，但第三方指数报价有效 | 保留指数原始值，成员行情标缺失，不重算指数 |
| 成员分页不完整或数量不可信 | 不覆盖完整成员版本，不以首屏冒充全量 |
| 当日价格正常、日线仍为昨日 | 分别显示真实日期，不构造今日K线 |
| 腾讯失败 | 仅对已验证精确映射尝试新浪；其他指数保持其发布方来源策略 |
| 当前榜整体失效 | 显示带实际日期的旧快照，当前比较摘要停止生成 |
| 本地无数据 | 开发预览可用醒目标记的Mock；生产绝不自动回退Mock |

不沿用观察池“样本至少3只、覆盖90%”的财务汇总门槛：第三方指数的原始涨幅不由本地成分采集比例决定。初次接入验证成员完整性，后续个股缺失只影响成分展示。

## 验收标准

1. 任一正式榜单值可以定位到第三方身份、原始字段、日期及时间；无本地板块收益公式。
2. 国证PCB、存储芯片、创业板算力、国证算力按各自代码显示，不能重命名成更窄的概念。
3. 成员全量与来源一致；默认仅20行、分页401、空目录等不会造成名单截断或清空。
4. 今日报价、昨日日线和昨日成员可同时存在且显示清楚；北京时间日线不因UTC错一天。
5. 无日期网页值、错误代码、未来时间、失效源不进入当前总结；个股缺失不改变第三方指数值。
6. 同花顺、国证及不同市场不混排；未接入领域仍可查接入原因。
7. 截图8只证券身份正确，港股时间与币种清楚；报价延迟未核验时不称实时。
8. 事实总结、来源展开、成分查看、个人关注、收盘留档和历史回看形成可用链路。
9. 本地Mock有独立标识，生产失败保留有效记录，不能用模拟数据补榜。
10. 桌面榜单与成员可同屏查看，移动端能切换视图，不出现横向挤压或大量空卡片。
