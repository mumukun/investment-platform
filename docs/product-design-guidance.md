# 产品设计指导

通用设计基线：Dashboard 仓库的 [产品设计规范 v1.0](../../investment-research-dashboard/docs/design/product-design-system.md)。仓库路径以 SYSTEM_MAP.yaml 为准；在各仓独立 checkout 时从业务仓库 README 的文档入口访问。

全部现有和新增界面使用暖灰/米白基础、品牌紫、薰衣草辅助色；区分行情、反馈与系统运行语义。新增页面先复用共享变量和组件，维护业务仓库 docs/design/interface-audit.md 的页面覆盖记录。详细色值、字号、布局、组件与验收规则只在业务规范维护，避免两份标准漂移。
