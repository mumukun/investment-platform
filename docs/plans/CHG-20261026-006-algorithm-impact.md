# 盘中候选算法影响评估

Change：CHG-20261026-006。2026-10-26，DRAFT。仅源码核查、合成敏感性分析与方案修订，未实现业务修复，未执行真实市场回放或收益回测。

## 1. 结论与取舍

直接把盘中值换成历史均值会影响当前算法，影响不只在展示：候选可能增加，也可能被误删，排名、结构状态和风险距离均可能变化。因此不采用统一替换。先修复已有有效结果被整包健康、扫描完成、缓存和前端刷新阻挡的问题；保留原资格、因子、窗口、权重、排序、状态转移和正式确认。历史 20 日均额只用于明确标记的补充观察，不能伪装成原算法已通过。

这不保证“原名单永远不变化”：当前行情变化、原来未处理的真实输入进入、过期结果被撤出，理应改变当前结果。要求的是同一时点、相同完整输入、相同统计样本和前序状态下，原算法结果完全一致；补充观察本身不能改变原结果。

依据源码：stock-analyzer `ca8b267ef2b0fc75666ff2335916b9e1f17dc7c0`；Dashboard `eb9788430ee2e06c5006ef19a9c647543daa90df`。本轮不从本地源码推断新的生产状态。

## 2. 输入分类与替代边界

以下“实时”指该规则要求时效内的实际盘中观察，不承诺逐笔推送。历史均值适合衡量常态；历史高低点、斜率、相对强度并非均值，须保持其各自公式。

| 输入/用途 | 必须使用什么 | 可用历史的边界及本次决定 |
| --- | --- | --- |
| 平常流动性 | 完成交易日成交额 | 波段已有 20 日均额，继续沿用。尾盘/短线动量原今日金额资格保留；新增观察可用前 20 日均额，门槛分别沿用尾盘 1 亿元、动量主板 8 亿元/其他已支持板块 3 亿元 |
| 历史量能结构 | 既有 5/20、10/60 等完成日窗口 | 波段这些特征已采用历史基准；保留原均值/比值/OBV 类算法，不要求今日全天成交额，不统一压成 20 日 |
| 均线、ATR 与波动 | 按各策略既有定义 | 尾盘 MA/ATR 原来就是完成日参考，可提前算；波段动态 MA/ATR 包含形成中的当天条，继续用最新价及实际高低价计算，不能改成昨日值 |
| 前高、前低、支撑、压力、趋势、位置 | 原 10/20/60/120 日结构与当前价 | 历史参考可缓存，当前距离/突破/跌破用最新价。原最高收盘价不换最高价，原排除今天的窗口不加入今天 |
| 历史相对强度 | 个股、指数/行业共同历史日期 | 历史 10/20 日强弱可复用，保持比较对象；不能用昨日指数/行业涨幅替代今天的相对强弱 |
| 当前涨幅、过热、日内位置、突破/失效 | 最新价、真实昨收、当日实际高低价、有效涨跌幅规则 | 必须盘中更新。历史均价/昨日形态不能说明今天仍在支撑之上，也不能让已跌破的股票继续合格 |
| 今日累计成交额/量、实际换手 | 截至当前实际累计值及有效股本口径 | 有值就使用，无值明确缺失；历史均值只能另列，不能填入今日字段或原排序因子 |
| 今日 VWAP | 当前真实金额/成交量，单位一致 | 历史均价不能代替。缺失只使依赖 VWAP 的确认不可判定，其他观察结果可以保留 |
| 同时间量比 | 今日实际累计量额与历史相同时段样本 | 分母可历史预计算，不能换历史全天均额。波段至少 15 个有效样本；短线动量保留自身至少 12 日要求，不统一阈值 |
| 盘中市场/板块强弱、广度与排名 | 当前真实可比成员和行情、原覆盖率/样本要求 | 不用历史平均涨幅/广度替代。不足时相关条件未知；补充观察不得改变原统计分母、分位数样本和评分 |
| 五分钟站稳、尾盘走势与成交增量 | 实际已完成的分钟观察、14:31 后时段样本等 | 不能由日线或历史均值推导；观察可先显示，正式确认保留原时间、覆盖率和连续性条件 |
| ST、停复牌、上市、涨跌幅、复权身份 | 当日有效的证券事实与一致价格尺度 | 可用仍有效的可信缓存，不求 20 日均值；未知/冲突不能猜，按股隔离 |
| 最终收盘价/全天金额、收盘确认天数、正式尾盘冻结、后续收益 | 对应事件真实发生后的事实 | 不能提前借用历史。盘中价格可作为 forming close 计算，不能计为最终日线或完成一次收盘确认 |

补充观察的 20 日窗口截至上一交易日，缺采不补 0、不跳日缩分母。原策略自己的历史长度和统计实现不因这条新增路径被改写。历史平均量/换手率在数据齐全时也能统计，但本次不增加新的选股因子。

## 3. 各模块影响与推荐

## 5. 实施验收与尚未验证

完整修复方案新增 T16/T17：

- 同一完整输入、同一状态/样本集合下，修复前后原资格、评分、档位、路径状态、关键位、失效位、风险距离、确认时间和正式名单逐项相同。
- 补充观察不进入原评分/分位数/市场统计集合，不挤掉或重排原合格结果；原实际金额达标但历史均额偏低的股票继续保留。
- 数据缺失最多增加明确待确认观察，不生成原规则通过或正式参与；不得用补充对象推进原状态机。
- 原短线动量、尾盘超短和波段身份及各自金额/同时间样本门槛保持；有真实缺失或失效则明确原因。
- 在数据许可时用同一批实际盘中输入作差异回放，单独解释“输入更新”“原算法差异”“仅补充观察”；之后再做正式发布授权范围内的交易时段验收。

本地实现后已完成原基线 e85c12c 在相同合成输入下的波段四项路径结果黄金回归；原尾盘、短线动量数学与补充观察隔离测试通过，纯规则引擎未修改。这些有限样本不能证明所有实际行情零差异。实际盘中回放、大规模端到端传播时延与收益评估尚未执行。最近结果延迟保留只改变展示可用性；原新增确认时效/参与规则保留，120 秒和示例 4 分钟均不是显示或验收硬门禁。详细实施、32 项门禁与 18 组验收见 [完整方案](CHG-20261026-006-intraday-candidates.md)。
